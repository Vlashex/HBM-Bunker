Defense door and hatch textures
==============================
The following PNG files are copied byte-for-byte from SecurityCraft v1.10.2.1
(Minecraft 1.21.1), by the SecurityCraft development team:

textures/block/defense_door_lower.png <- assets/securitycraft/textures/block/reinforced_door_lower.png
textures/block/defense_door_upper.png <- assets/securitycraft/textures/block/reinforced_door_upper.png
textures/block/defense_hatch.png <- assets/securitycraft/textures/block/reinforced_iron_trapdoor.png
textures/item/defense_door.png <- assets/securitycraft/textures/item/door_indestructible_iron_item.png

Source: https://github.com/Geforce132/SecurityCraft/tree/1.21.1
License: https://github.com/Geforce132/SecurityCraft/blob/1.21.1/LICENSE
V1/V2/V3 darkening is applied by JSON tint indexes and client color handlers.
No source PNG pixels were edited. Door/hatch model geometry follows Minecraft's
standard block templates; Minecraft textures used by reference are not copied.
