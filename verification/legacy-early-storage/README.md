# Раннее хранение SRP-форка — 20.10.2026

Срез: Simple Storage Network 1.12.2-2.0.1, HBM CE 2.6.1.0,
Forge 14.23.5.2860, CraftTweaker 4.1.20.698, MixinBooter 11.18.
CTM включён только в клиентский архив. Полный состав SRP-форка не собран.

## Результат

- 26 Python-проверок (18 унаследованных + 8 новых) прошли.
- 25 нативных утверждений прошли, `native-checks.json`.
- Все пять реальных рецептов сопоставлены нативным IRecipe.matches;
  количество выхода сверено через getCraftingResult. Для каждого выхода
  остался ровно один рецепт. Слиток вместо HBM-пластины не подходит.
- В новом мире проверены настоящие Master, Request Table, два Link Cable,
  два обычных сундука: агрегация 19+13, симуляция извлечения без изменений,
  извлечение 7 и обратная вставка без потерь/дюпа, связь Request Table с Master,
  NBT round-trip Master и отключение одного сундука с сохранением предметов.
- Тестовый сервер был доступен только на 127.0.0.1:25585 и завершился штатно,
  exit 0. Действующий игровой сервер и клиент не изменялись.
- Интерфейс клиента/поиск с клавиатуры и реальный GUI-крафт визуально не проверены.
  Подтверждён серверный backend терминала; это не свидетельство полного клиентского QA.
- Нативный конфиг ProjectE содержит EMC=0; работа именно ProjectE в этом
  минимальном профиле не проверялась, поскольку сам ProjectE в него ещё не включён.

## Разбор неуспешных попыток

Первая попытка прошла рецепты, но reflection тестового модуля запросила
клиентский ITooltipFlag на dedicated server. Выбор базового Block устранил
ошибку инструмента. Вторая читала сеть до отложенного refresh: добавлен её
обычный native update без ожидания 200 ticks. Третья ожидала, что insertStack
возвращает вставленное количество; код SSN возвращает остаток. Итоговая проверка
проверяет остаток=0 и независимый общий итог=32. Каждая попытка использовала
отдельный новый мир, ранние результаты не выданы за успешные.

Сырые журналы, JAR, миры и тестовый probe не входят в клиентский/серверный архив.
Исходник probe: legacy/storage/verification/StorageProbe.java.

## Повторение

```powershell
python -m unittest discover -s tests -v
python tools/legacy_storage.py check
python tools/legacy_storage.py build
```

Для нативного прогона установить закреплённый Forge в новую тестовую папку,
добавить только server-entries среза и отдельно собрать StorageProbe.java
с fixture.properties из recipes.json. Нельзя использовать рабочий мир.
