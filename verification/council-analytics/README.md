## Найдено и исправлено до выпуска

Независимый review выявил3 проблемы: предел NBT-string65535байт, несовпадение
8MiB лимита сохранения/1MiB parser и trimming до восстановления endedTick.
Каждая воспроизведена падающим regression-тестом и исправлена. Проверены
настоящие compressed NbtIo round-trips: штатные32×48 Unicode, максимум128×128
с JSON больше1MiB, legacy schema1, malformed UTF-8 и уменьшение лимита операций.

Та же проблема NBT-string обнаружена в старой очереди и owned ledger:
отдельный regression с512 history и128×32 owned UUID прошёл путь RED→GREEN.
Схема2 использует UTF-8 byte array; строгие лимиты/защита unknown сохранены.

Первый native запуск дал2 ошибки в fixture: тестовый игрок ещё находился
в штатной60-tick join invulnerability Minecraft. Причина подтверждена кодом
ServerPlayer.hurt. Только тестовый setup снимает этот отдельный join grace;
боевые игровые guards не менялись. После исправления второй свежий мир25/25.
Оба мира/лога сохранены локально вне Git, предыдущие результаты не затирались.
