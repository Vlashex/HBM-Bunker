# Еда и вода — проверка 5.2.0

Minecraft 1.21.1 / NeoForge 21.1.262; Farmer's Delight 1.3.4 и
Thirst Was Reclaimed 3.0.6. Машинные результаты: [report.json](report.json).

Проверки выполнены в новых отдельных папках, без изменения игрового мира:

- `build runGameTestServer -PdeadEarthGameTestDirectory=run-gametest-food-green-2`
  — 180 Java unit и 94 обязательных GameTest; все прошли. Игровой набор занял
  33,01 секунды, полный запуск Gradle с загрузкой модов — 2 минуты 16 секунд.
- Четыре новых нативных теста: очистка воды 0 → 2 → 3; обе бутылки из стопки,
  включая последнюю, дают жажду ровно один раз и возвращают тару; супы утоляют
  голод и жажду; четыре ранних рецепта культур и штатная кухня; отсутствие
  девяти дикорастущих культур/колоний в возможных биомах Overworld.
- Исходный Thirst Was Taken 2.1.5 воспроизвёл дефект последней бутылки.
  Выбранный форк прошёл ту же проверку. Вместе оба JAR не устанавливаются.
- Отдельный дефект тестовой фикстуры индекса турелей устранён ожиданием
  фактического entity-ticking чанка вместо фиксированной задержки.
  Производственная логика индекса не менялась; исправление — отдельный коммит.
- 16 тестов упаковщика и `python tools/release.py check` прошли.
- Read-only ревизия JAR/зависимостей, TOML, рецептов и EMC не выявила важных
  проблем. Прежние EMC и рецепты металлургии сохранены.

Обычный сервер `run-server-food-1` поднял новый мир на `127.0.0.1:25566`.
Настоящий клиент `run-client-food-1` загрузил оба новых мода, подключился и
прошёл автоматическую проверку. Активен `IrisRenderingPipeline`, MakeUp
включён, fallback/error отсутствуют, OpenGL error = 0. Клиент завершился
сам; тестовый сервер штатно остановлен через его отдельный RCON.
Основной сервер на 25565 не затрагивался.

При выгрузке обнаружено 11 ошибок сохранения `minecraft:arrow`: пустой
ItemStack в `AbstractArrow.addAdditionalSaveData`. Сервер завершился штатно,
но эти стрелы не сохраняются. Связь с новыми модами не установлена;
предварительный аудит указывает на старый путь `ImprovedMobs BowHandler.use`,
передающий непроверенный результат `getProjectile`. Причинность требует
отдельной проверки и не считается доказанной по одному стеку вызовов.

Prism ZIP собирается штатным `python tools/release.py build`: SHA-256 и
размер каждого JAR проверяются по lock, CRC архива проверяет сам упаковщик.
Контрольные суммы выпуска находятся рядом с архивом в `dist/SHA256SUMS.txt`.

Не проводились длительный балансировочный сеанс и визуальная оценка HUD.
Computer Use и снимки экрана не использовались. Проверка Iris подтверждает
активный pipeline без ошибок OpenGL, а не сравнительный FPS-бенчмарк.
Работающая игровая установка не обновлялась и не останавливалась.
