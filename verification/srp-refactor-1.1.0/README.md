Native/restart использовали JAR32279af52e6b5a082d1b07aaa134fa9321f7589fab534459993a07b3170add80. Клиент выявил отсутствующую particle-текстуру 12 сеток. Финальный JARccbd76362d16064f461e0c2ca0aa9ba58c0f69214165021f77ea2afffeaebafa содержит только эту поправку ресурсов: все классы, все non-assets entries и остальные assets побайтно идентичны. Это связывает серверные результаты с финальным клиентским JAR без повторного полного прогона неизменного игрового кода. [Проверка эквивалентности](resource-only-proof.json).

Физический бой проверен на обычных тиках: групповая ответная агрессия животных, обнаружение SRP за непрозрачной стеной, прокапывание и реальный урон игроку; три вида/стадии SRP. Враг подходит к загрузчику, разрушает его с одним дропом, уважает конечные HPV3, стартовую защиту и паузу без игроков. Грядки проверены через настоящие инвентарные capability, Bonsai — штатными кликами/ростом/урожаем/выгрузкой в сундук.

Ручная оценка ответов ИИ сохранена в [ai-manual-review.json](ai-manual-review.json). Выбор события приемлем для замороженной ситуации; причина критика repetition не подтверждена пустой историей. Преимущество dual над single этим примером не доказано. Вызовы моделей не запускали боевые сценарии в пользовательском мире.

Ограничения: это функциональные и интеграционные проверки, без нагрузочного бенчмарка и длительного кооперативного прохождения. Пять клиентских кадров сняты в CALM. На кадре пустоши туман и высота платформы мешают оценить грунт; генерация подтверждена отдельной native-проверкой трёх регионов. `intermediate-native.json` сохраняет промежуточные результаты и не служит подтверждением выпуска. Неудачные визуальные попытки сохранены локально; в итог принят только успешный полный аудит с корректным разрешением ленивых моделей VintageFix.
