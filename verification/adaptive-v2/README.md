# Проверка v2 — эволюция, HP/урон и серверный конфиг

99 Java unit-тестов, 39 GameTests с полным составом модов и 13 проверок упаковки
прошли. Активные игровые проверки заняли15.24с, холодный запуск с ними —2мин9с.

Нативный Mutationcraft.tickTime и настоящие PhaseData.addPoints Overgrown получили
×1.5 при давлении1.5. Календарь сезонов при этом не изменился. Проверены настоящие
Stats игроков, исключение creative, очистка baseline при logout, NBT checkpoint
и пределы/влияние настроек. Два дополнительных игровых regression сначала
воспроизвели ошибки выбора канала putrid и нейтрального отключения; затем прошли.
Интервалы экспозиции проверены детерминированно, без ожидания их общего кратного.

Отдельный сервер обновил существующий тестовый мир v1. Настройки изменены на
maxAboveBase0.25, healthInfluence0.5, damageInfluence0.75, phaseMinutes35. При
давлении1.2 показаны HP×1.1/урон×1.15; зимой эволюция паразитов×2.16, лес×0.3,
HP паразитов×1.98/урон×2.07. Текущий сезон сохранил48000 ticks, прогноз следующих
фаз использовал42000. Настоящий клиент получил35/0.25/0.5, отрисовал зиму, прошёл
tooltip-проверку и штатно завершился. Изображение корки визуально проверено.

После restart сохранены campaignId, весь климатический snapshot, 6533 активных
ticks и давление1.2. Временная тестовая подмена зимы завершилась, как предусмотрено.
Без игроков активное время не продвинулось. Оба тестовых сервера штатно остановлены.

Проверка упаковки нашла пропуск связанного отчёта в старом архиве1.0.0; начиная
с2.0.0 в ZIP входят отчёты, связанные изображения и TOML-пример. Старый тег не
перезаписывался. [Полный конфиг](../../docs/examples/dead-earth-server.toml),
[описание](../../docs/DEAD-EARTH-ADAPTIVE.md).

Нагрузка шести реальных игроков и импорт в пользовательский Prism не проверялись.
Пользовательские миры не затрагивались. Полные сезоны проверялись расчётом, без
многочасового ожидания в игре. Это локальный релиз, публичная публикация не делалась.
