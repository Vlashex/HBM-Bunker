# DEAD EARTH SRP 1.0.0 — локальный функциональный выпуск

Итоговый срез прошёл 286 записей native Forge-проверок /14 групп, bridge27,
Python47 и настоящий restart47. Сохранённая партия компактного сита проверена
через другой JVM, без повторной траты/выдачи. Оба реальных клиента подключились
к новому `world-wasteland`, старый серверный и одиночные миры сохранены.
CPU-ИИ и админка запущены. Пользователь затем открыл одиночный мир во втором
клиенте; работающие окна оставлены ему.

- Три архива, SHA-256, CRC, пины и Java8: [artifacts.json](artifacts.json).
- Последний серверный прогон: [native-latest.json](native-latest.json).
- Последний настоящий перезапуск: [restart-latest.json](restart-latest.json).
- Два игровых клиента и ссылки текстур: [client-launch.json](client-launch.json).
- Область готовности и ограничения: [readiness.json](readiness.json).
- Модельный пример и ручной разбор: [manual-model-review.md](manual-model-review.md).

Сита III/IV/V используют81/729/6561 исходных бросков. В native проверены81
сравнение выдачи, блокировка выхода, NBT, разборка/установка и сохранённая ссылка
на обработчик; 25 обычных сит расходовали25 блоков и продвигались центральным
кликом. 19 профилей дают68 новых блоков сжатия. Булыжник, дроблёные андезит/гранит
сжимаются для хранения; просеивание доступно там, где его поддерживает родной реестр.

Предыдущие снимки `native-full.json`, `restart.json`, `real-ai.json` сохранены
с прежними границами: модельные single/dual вызовы реальны, участник там fake
survival player. Один выбор не подтверждает улучшение тактики. В latest native
не наблюдались HBM ore/architecture samples для соответствующих preservation
assertions; deferred HBM ore callbacks не подтверждены. Pending грядки и рудного
переработчика через другой JVM не проверялись. GUI-получение из наковальни и
человеческая визуальная оценка не зафиксированы. Нагрузочные тесты не проводились.
Forge пропускает необязательные Ex Nihilo recipes для отсутствующих
Forestry/Thermal; собственные CraftTweaker recipes загружены без ошибок.

Локальная метка выпуска: `srp-v1.0.0`; публичная публикация не выполнялась.
Контрольные суммы сохранённых свидетельств: [manifest.json](manifest.json).
