# SRP 1.0.1 — тестовый клиент

Автоматические сита сохранены по последнему уточнению пользователя. Правила4/12кликов не входят в сборку.

Подтверждено:56 Python-проверок,7 Java-наборов,290 записей полного сервера Forge и27 bridge/admin проверок. Семь реальных сит (III/IV/V survival/creative и native hoppers) завершили81/729/6561 нативных просеиваний на обычных тиках; точный перенос награды пустой рукой,0 chat packets. Проверены паковка/повторная установка и NBT без изменения schema1.

Поверхность:3 отдельных района,75 наблюдаемых чанков,17141 почвенная колонка;0 пропущенной травы/земли,3069 защищённых от кратеров колонок безопасно перекрашены. Гранит и диорит соседних нативных жил учитываются отдельно как инертная порода. Реальные HBM architecture samples сохранены; deep HBM ore samples в этой выборке не встречены — см. surface.json.

242 модели статически разрешают нативные parent/textures. OpenGL-попытка не завершена: вспомогательный сервер не смог вызвать package-private конструктор ClimatePacket до READY. Исправлен только тестовый companion; повторный автоматический запуск отложен, когда пользователь запросил игровой клиент. Наличие screenshot/проверенных живых названий и оттенков не заявляется. Пользователь тестирует настоящий клиент на свежем серверном мире. Предыдущие миры и одиночные сохранения не удалены.

Полные журналы, миры, пароли и runtime-дескрипторы не включены. Нагрузочных замеров не было. Веса ИИ и тактика не изменялись; свежий bridge-прогон использует фиксированный selector, не реальную inference.

Первоначальные отказы были в контрактах probe: каменные варианты ошибочно считались пропущенной почвой,19-блочная площадка выходила за загруженный радиус, а Forge может вернуть PASS после успешного empty-hand block activation. Текущая проверка требует точного изменения инвентаря; production-код ради возвращаемого значения не менялся.
