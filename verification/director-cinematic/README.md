# Промежуточная проверка интерактивного режиссёра

Рабочий срез, не новый релиз. Последний выпуск остаётся 3.1.0 (D1 preview).

17 октября 2026: Java `test build` — 141 проверка; полный состав модов в новом мире `run-gametest-cinematic-full-5` — 68 GameTests, все прошли за 26,80 секунды после запуска мира. Python gateway — 30, упаковка — 13, `release.py check` прошёл.

Проверены зарегистрированные звуки/сущности, физические следы/волна/реакция игрока, пропуск закрытого случайного loot и включение после открытия, выбор альтернативной высоты, изоляция нечитаемого файла, отменённая и настоящая добыча, навигационная команда с отличающимися key/role, сохранение UUID живой выгруженной волны. Сохранённые сигналы допускают перестановку, но не дубликаты. Очередь/APPLYING проверены управляемым временем.

Навигационный тест фиксирует переданную нативному AI команду, а не гарантирует нахождение пути. Кооператив 2–6 игроков и длительная нагрузка не подтверждены этим коротким прогоном.

Сквозной прогон `run-server-cinematic-live-5` прошёл: реальная CPU-модель поставила interrupted_harvest за 30,078 секунды (337 входных / 7 выходных токенов), повтор вернул already_queued, 16 наблюдений загруженной модели дали 0 байт VRAM. Клиент передал шесть следов; снимок просмотрен, рисунки видны. Одно показание FPS — 60.

Для этого ограниченного теста интервал повторного сканирования ресурсов увеличен только в fixture: снимок оставался стабильным. Ускорения игровых часов нет. Генерация шла при работающем сервере и загрузке клиента; FPS во время активной генерации в уже отрисованном мире не измерен. Короткий прогон не является нагрузочным тестом кооператива. Клиент и сервер штатно завершились, мир сохранён. Единый BAT остаётся следующим обязательным срезом. Миры, дескриптор моста и полные журналы в Git не включаются.

Крупный план следов: trace-closeup.png, настоящий клиент 1600×900. Коричневый рисунок claw_1 и зелёный spore_1 видны на траве; посторонние эффекты игрока исключены кадрированием камеры. Визуальная часть пока представляет простые маски на поверхности.
