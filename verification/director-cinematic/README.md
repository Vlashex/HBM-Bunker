17 октября 2026: Java `test build` — 141 проверка; полный состав модов в новом мире `run-gametest-cinematic-full-5` — 68 GameTests, все прошли за 26,80 секунды после запуска мира. Python gateway — 30, упаковка — 13, `release.py check` прошёл.

Проверены зарегистрированные звуки/сущности, физические следы/волна/реакция игрока, пропуск закрытого случайного loot и включение после открытия, выбор альтернативной высоты, изоляция нечитаемого файла, отменённая и настоящая добыча, навигационная команда с отличающимися key/role, сохранение UUID живой выгруженной волны. Сохранённые сигналы допускают перестановку, но не дубликаты. Очередь/APPLYING проверены управляемым временем.

Навигационный тест фиксирует переданную нативному AI команду, а не гарантирует нахождение пути. Кооператив 2–6 игроков и длительная нагрузка не подтверждены этим коротким прогоном.

Реальная модель уже выбирала события в промежуточных запусках. Итоговый совместный прогон модели/отрисованного клиента ещё выполняется; успешного результата здесь пока нет. Единый BAT остаётся следующим обязательным срезом. Миры, дескриптор моста и полные журналы в Git не включаются.
