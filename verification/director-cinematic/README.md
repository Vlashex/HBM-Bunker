# Промежуточная проверка интерактивного режиссёра

17 октября 2026. Рабочая ветка после 3.1.0; новый релиз ещё не создан.

- Java `test build`: 136 проверок, 0 ошибок/пропусков.
- Python gateway/host: 30 проверок, включая настоящий MCP stdio и HTTP-контракт CPU-модели.
- Упаковка: 13 проверок и `release.py check`. Это проверка канонических входов, не выпуск нового ZIP.
- Три GameTest полного состава модов в новом отдельном мире `run-gametest-cinematic-interaction-1`, 6.099 с после старта: все звуки/сущности каталога зарегистрированы; настоящий след не мешает последующему пространственному звуку и спавну Mutationcraft; настоящее действие игрока над следом меняет сохранённую ветку. Этот игровой прогон предшествовал последующему переносу оставшихся числовых параметров в конфиг; после него прошёл Java unit/build, общий игровой регрессионный прогон ещё запланирован.

Предыдущий red-1 мир воспроизвёл блокирование следующих эффектов нашим следом; он сохранён. Отдельные RED→GREEN проверки воспроизвели потерю действия игрока между предвестниками, ранний старт окна реакции, повтор APPLYING после ошибки диска и устаревший бюджет после ожидания модели. Сохранённая очередь, неизвестная схема и прерванный эффект проверены отдельно.

Каталог: 15 разных графов, 103 звука, 48 масок следов. Таймеры ядра проверены подставленными часами, не ожиданием полного игрового интервала.

Клиентский рендер, реальный выбор события Qwen на этом контракте, все виды действий игрока и общий регрессионный GameTest-прогон ещё не подтверждены. HTTP-тест модели не является измерением реальной Qwen. Три физических теста не доказывают полноценное прохождение всех 15 событий или нагрузку кооператива. BAT ещё не реализован. Пользовательские миры и Prism-профили не изменялись.
