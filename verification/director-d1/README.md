# Проверка режиссёра D1 на CPU

17 октября 2026, версия 3.1.0. Срез D1 создаёт и проверяет предложения,
но не выполняет атаки и не изменяет блоки нейросетевым текстом.

## Реальная модель и обычный сервер

Qwen3.5-4B Q4_K_M, Ollama 0.40.6 в Docker Engine 29.9.1 / Ubuntu WSL 2.
ПК: Xeon E5-2678 v3, 12 ядер / 24 потока, 32 GiB RAM.
Модель ограничена четырьмя CPU и 6 GiB. GPU контейнеру не передавался;
запрос дополнительно задаёт num_gpu=0 и think=false.

| Наблюдение | Результат |
|---|---|
| Полный запрос модели с подготовкой ответа | 25.687 с |
| Вход / выход | 224 / 27 токенов |
| Скорость активных часов сервера во время запроса | около 20 TPS; выборка 25 отсчётов, оценка 20.05 |

| Завершение | отдельный сервер сохранил мир и штатно остановился |

Сервер работал с полным составом модов и одним встроенным тестовым игроком.
Его часы не ускорялись и не замедлялись. Использован обычный runServer,
а не ускоренный GameTestServer. Время ответа включает холодную загрузку модели;
это один замер, не оценка долгосрочного p95.

В тестовой зоне наблюдались четыре алмаза: 32768 EMC, вклад 3.2768.
Снимок оставался неполным, включая неизвестный контейнер, поэтому D1 выбрал
наблюдение кампании и не сделал предположение об уязвимости зоны.
Выбор полной зоны, отбрасывание неполной/старой/переполненной и смена условий
отдельно проверены управляемыми unit-тестами.

Данные: [CPU и сквозной цикл](cpu-integration.json),
[итог отдельного сервера](server-status.json).

## Автоматические проверки

- 117 Java unit-тестов: политика, сроки и конфиг, протокол, сохранения, прежние механики.
- 59 GameTests полного состава модов в отдельном свежем мире, 20.61 с после запуска.
- 24 Python-проверки gateway/режиссёра, включая настоящий MCP stdio round-trip.
- 13 проверок упаковки и отдельный release check.

У D1 нет нового клиентского интерфейса или сетевого сообщения клиенту.
Рендерящий клиент вместе с моделью и кооператив на шесть игроков не проверялись.
Стабильность FPS и нагрузка будущих атак из этого короткого теста не следуют.
Пользовательские миры и профили PrismLauncher не изменялись.

Часы политик и 15-минутные интервалы проверены подставленным временем, без
ожидания полных игровых интервалов. Реальное ожидание нужно было только для
старта обычного сервера и фактической генерации модели.
