# Проверка сезонов 1.0.0

90 Java unit-тестов, 30 GameTests с полным составом модов и 13 тестов упаковки прошли.
Выполнение игровых проверок заняло 17.47с; весь холодный запуск — 2мин16с.
Четыре предварительно воспроизведённые ошибки получили проверки RED→GREEN:
летний/зимний порог настоящей эволюции Mutationcraft, выход игрока из Overworld,
отсутствие загрузки соседнего чанка погодой. Отдельно проверены PositionCheck и
FinalizeSpawnEvent запреты сезонного дополнительного спавна.

Площадка спавна удерживается самим тестом; разрешения размещения отделены от
проверяемых запретов. Игровые погода и дополнительные мобы новые чанки не загружают.

Настоящий отдельный клиент подключился к выделенному loopback-серверу полного
состава: зима отрисована, переключение на лето выполнено, tooltip прошёл, клиент
штатно завершился. После перезапуска того же мира campaignId, климат и 5865 активных
ticks сохранились; без игроков часы не продвинулись.

[Скриншот ледяной корки](ice-crust.png) снят на отдельной лесной площадке с деревьями
vanilla и Overgrown Vegetation. Снимок сделан до исправления счётчиков, после
исправления рендера; внешний вид итоговой версии сохранён.

Не проверялись нагрузка шести реальных игроков и импорт в пользовательский Prism.
Полный 160-минутный круг проверен логически без ожидания в мире. Пользовательские
миры не использовались. Подробности: [сезоны](../../docs/DEAD-EARTH-SEASONS.md).
