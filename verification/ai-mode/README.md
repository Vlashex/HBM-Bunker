# Переключение single/dual и выгрузка критика — 18.10.2026

Проверка через настоящий HTTP-маршрут админки `/api/ai-mode`, локальный CPU
Ollama0.40.6 и существующие закреплённые веса Qwen3.5-2B. Никаких игровых
сохранений, RCON, скриншотов или Computer Use. Рабочая установка не обновлялась.

[Результат настоящего измерения](real-unload.json).
Отдельный тестовый контейнер: CPU4, лимит6GiB, один runner, порт127.0.0.1:11435,
те же веса из read-only volume. Критик предварительно загружен на2минуты
с num_gpu0/context4096, затем через операторский HTTP выбран single.

Переключение с подтверждением заняло0.563сек в простое. Это не обещание такой
же задержки при активной генерации: она завершается в своём timeout до90сек.
Anonymous memory — не весь cgroup working set; файловый кеш ОС может остаться.

Первый диагностический контейнер завершился до вызова модели (exit0, OOM=false);
проверка недоступного API не считалась успешной выгрузкой. Для принятого замера
использован отдельный контейнер с удерживаемым WSL-сеансом. Исходные
папки неудачных проб сохранены вне Git.

Автотесты покрывают переключение во время proposal/critique/revision,
сохранение исходного выбора, повторный dual без предварительной загрузки,
реальный digest alias, запрет выгрузки primary при ошибочном pin,
отсутствие ложного подтверждения при ошибке/оставшемся runner,
UUID/CAS/повтор запроса, unknown DB без перезаписи, Origin/nonce и UI-статусы.
Полный Python-набор: **132/132**,48.197сек. Пять DOM-наборов прошли, включая
новый ai_mode_ui_test. Упаковщик: **17/17** и release.py check; статические
JS/CSS ссылки админки проверяются по фактически отбираемым файлам архива.

Java/состав модов не изменялись; Minecraft GameTests для этого UI/Python-среза
повторно не запускались. Игровые25/25 из5.5.0 остаются историческим результатом,
