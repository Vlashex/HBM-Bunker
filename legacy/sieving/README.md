# Compact native sieves

Ordinary Ex Nihilo I processes 1 raw block; Ex Compressum heavy II processes 9 after the shipped zero-loss policy. III/IV/V are one block each and process 81/729/6561 raw equivalents from ONE correspondingly compressed block (compression power 2/3/4). Raw input and wrong compression levels are rejected. There is no free multiplier on one ordinary block.

Frames cost nine previous frames: II uses nine ordinary sieves (preserving the HBM plate route), III uses nine heavy frames, then IV/V use nine previous compact frames. Four native mesh grades stay separate. Native II reuses native meshes; III costs nine native meshes of the SAME grade, IV/V cost nine previous compact meshes of that grade. Meshes do not wear or receive invented Fortune; native reward rolls use their grade and Fortune 0.

19 material profiles have 68 own placeable compressed storage blocks. Reuse the eight native Ex Compressum first-compression blocks; add own powers 2/3/4. Red sand, six leaves, crushed diorite/andesite/granite and crushed skystone have own powers 1..4. All compression/decompression recipes exchange exactly nine adjacent-level blocks. The active native pack currently sieves 16 profiles; cobblestone, crushed andesite and crushed granite are storage/compression profiles and are rejected by the sieve when the native registry has no reward table. Crush raw cobblestone before compressing for sifting. Heavy-hammer integration for higher compression powers is not implemented.

Install a matching-tier compact mesh BEFORE loading exactly one matching compressed block. Input without a mesh is rejected, including simulated and actual hopper/capability insertion. Loading is separate from FOUR manual work clicks. The fill drops 4/3/2/1/0; native draws start only after the first work click, and loot remains private until both all draws and the fourth click complete. The fourth click/completion transfers all fitting stacks to the nearby activating player's main inventory; overflow stays in the frame for collection or hopper extraction. Four clicks authorize the complete81/729/6561 batch, never one raw block. No chat, automatic next batches or giant stacks. Shift with an empty hand removes unstarted input before its mesh. Side handlers can extract only output; input and mesh slot limits are1.

All loaded machines share at most 256 native reward draws per server tick by default; config permits 1..256. Native reward calculation runs under that shared bound so it never performs 6561 rolls inside a single player packet. Weak references retain only logical-server loaded tiles. Owner-thread processing never loads chunks. Each raw draw calls the actual Ex Nihilo SIEVE_REGISTRY.getRewardDrops(Random, rawState, nativeGrade, 0), so all additive HBM resources, leaf drops and AE2 crystal-seed NBT are preserved. No fake block, world drops or alternate reward table is used.

A party consumes its compressed input once, records its raw identity, grade, deterministic seed and remaining cursor in the same tile NBT, and commits each already rolled draw into a bounded aggregate bank. Bank prototypes always have count1; quantities use NBT integers, never oversized ItemStack counts. Completed loot refills the output slots without rerolling. Breaking returns exactly one placeable frame containing the inventory and remaining party in BlockEntityTag; placement uses native ItemBlock restoration. Empty frames drop without NBT and can be upgraded; packed frames are excluded from upgrade recipes. Invalid/unknown saved data stays preserved inside a stopped frame.

Lifecycle API: LegacySieving.install(Path), registerBlocks(Object), registerItems(Object), registerModels(), tick(LegacyRuntime), close(). Source descriptor materials.json includes raw IDs/metadata, native/own first compression, and every own block with 9^power raw equivalent. heavy-entries.json is a plain array of native Ex Compressum generation entries for active own first-compression inputs; root full recipe generator merges it. Own generator tools/legacy_sieving_recipes.py emits scripts/config/assets and separate lang fragments for the root shared-language merge.

Deferred physical entry point: dev.deadearth.legacyprobe.sieving.SievingProbe.run(LegacyRuntime,Object world,Object player,int x,int y,int z) returns Map<String,Object> and throws Exception. It checks 81 real native draws, HBM table inclusion/output equality, spent input, mesh lock, hidden/reloaded bank and pending, native break/place, empty-frame upgrades and the global quota. The full native harness verifies gameplay after the completed patch is compiled.

The empty model is the native open Ex Compressum frame. Installed mesh and four fill heights derived from manual work clicks are synchronized to clients; the visible material uses native textures. All own compressed cubes keep the native material with progressively darker tint. Sieve interactions emit no chat messages. The normal gameplay probe uses real PlayerInteractionManager activations and ordinary END ticks, including native feed/output hoppers.

Schema2 persists manual strokes, native seed/cursor, pending draw, aggregated reward bank (count1 prototype + bounded int amount), and a one-shot delivery UUID. Schema1 remains readable: already-consumed active batches finish without rerolling and old queued inputs up to64 are conserved by keeping one in the input slot and refunding the surplus as compressed blocks in the output bank (all are refunded if the mesh is absent). New insertion always accepts at most1. Hidden incomplete rewards cannot deadlock on the27 public output slots. Creative overflow uses Forge inventory insertion, avoiding vanilla creative discard behavior.
