# Compact native sieves

Ordinary Ex Nihilo I processes 1 raw block; Ex Compressum heavy II processes 9 after the shipped zero-loss policy. III/IV/V are one block each and process 81/729/6561 raw equivalents from ONE correspondingly compressed block (compression power 2/3/4). Raw input and wrong compression levels are rejected. There is no free multiplier on one ordinary block.

Frames cost nine previous frames: II uses nine ordinary sieves (preserving the HBM plate route), III uses nine heavy frames, then IV/V use nine previous compact frames. Four native mesh grades stay separate. Native II reuses native meshes; III costs nine native meshes of the SAME grade, IV/V cost nine previous compact meshes of that grade. Meshes do not wear or receive invented Fortune; native reward rolls use their grade and Fortune 0.

19 material profiles have 68 own placeable compressed storage blocks. Reuse the eight native Ex Compressum first-compression blocks; add own powers 2/3/4. Red sand, six leaves, crushed diorite/andesite/granite and crushed skystone have own powers 1..4. All compression/decompression recipes exchange exactly nine adjacent-level blocks. The active native pack currently sieves 16 profiles; cobblestone, crushed andesite and crushed granite are storage/compression profiles and are rejected by the sieve when the native registry has no reward table. Crush raw cobblestone before compressing for sifting. Heavy-hammer integration for higher compression powers is not implemented.

Insert a matching compact mesh and compressed block by right-click or hopper. The machine processes the party automatically without FE. Empty-hand right-click takes one output stack; sneak with an empty hand returns mesh/input while idle. The capability has input slot 0, mesh slot 1 and 27 output slots (2..28). During an active party, input and mesh extraction are locked. Output extraction stays available.

All loaded machines share at most eight native reward draws per server tick; config permits 1..8. Weak references retain only logical-server loaded tiles. Owner-thread processing never loads chunks. Each raw draw calls the actual Ex Nihilo SIEVE_REGISTRY.getRewardDrops(Random, rawState, nativeGrade, 0), so all additive HBM resources, leaf drops and AE2 crystal-seed NBT are preserved. No fake block, world drops or alternate reward table is used.

A party consumes its compressed input once, records its raw identity, grade, deterministic seed and remaining cursor in the same tile NBT, and retains one already rolled draw while output is blocked. A draw streams through the output slots without rerolling. Breaking returns exactly one placeable frame containing the inventory and remaining party in BlockEntityTag; placement uses native ItemBlock restoration. Empty frames drop without NBT and can be upgraded; packed frames are excluded from upgrade recipes. Invalid/unknown saved data stays preserved inside a stopped frame.

Lifecycle API: LegacySieving.install(Path), registerBlocks(Object), registerItems(Object), registerModels(), tick(LegacyRuntime), close(). Source descriptor materials.json includes raw IDs/metadata, native/own first compression, and every own block with 9^power raw equivalent. heavy-entries.json is a plain array of native Ex Compressum generation entries for active own first-compression inputs; root full recipe generator merges it. Own generator tools/legacy_sieving_recipes.py emits scripts/config/assets and separate lang fragments for the root shared-language merge.

Deferred physical entry point: dev.deadearth.legacyprobe.sieving.SievingProbe.run(LegacyRuntime,Object world,Object player,int x,int y,int z) returns Map<String,Object> and throws Exception. It checks 81 real native draws, HBM table inclusion/output equality, spent input, mesh lock, blocked/reloaded pending, native break/place, empty-frame upgrades and the global quota. Root owns final server/restart/client execution. No game or tests were run during this feature authoring.
