# Legacy finite defense

Nine own blocks: wall/door/hatch V1=1000, V2=2000, V3=8000 HP. Native paired door and trapdoor collision/hand opening/redstone are retained. Own riveted steel sprites darken by tier; model geometry comes from our existing modern defense assets. They are not unbreakable or nuclearproof.

Integration: `LegacyDefense.install(config)` in preInit; `registerBlocks(registry)`, `registerItems(registry)`, `registerModels()` in the existing native events. The World.setBlockState guard calls `allowChange(world,pos,proposedState)` before the grace policy. A same-block state update never spends HP. The hook classifies only SRP/ESM call chains as hostile; unknown writers, HBM nuclear writers, native support updates and players keep normal behavior. `isDefense(block)` is available to climate/coordinator adapters. `close()` flushes the bounded admitted attack queue and clears the world-local references on server stop.

Hostile destructive writes consume100 HP with a shared20tick cooldown per anchored block. `ExplosionEvent.Detonate` removes defense positions from vanilla destruction and spends250HP per explosion power (default TNT1000HP), independently of the hostile cooldown. Doors share the lower-half record and terminal damage removes both halves. Native ESM harvests even when destroyBlock returnedfalse; our own HarvestDropsEvent filter prevents that hostile drop duplication, including silk, while native player drops remain enabled. Blocks cannot be piston moved. Native ESM zombie/husk allowlists explicitly contain all9defense IDs; pinned canHarvest requires nonnegative hardness and has no upper-hardness setting, so own hardness5 remains eligible.

Sparse damage lives in world/data/dead_earth_defense.json. Pristine blocks consume no records; HP and hostile cooldown survive reload. Terminal/remodeled blocks remove the record. Bounds32768 damaged blocks; at saturation a new damage record is rejected as nonterminal; journal capacity cannot fabricate zero HP or destroy a pristine block. Existing damaged blocks continue to lose HP and release their records on removal. Unknown/corrupt files remain untouched and hostile damage stops with an error; player removal stays possible. Explosion damage uses one durable snapshot for the complete affected set before any terminal removal, followed by at most one cleanup snapshot. Hostile writes coalesce by anchor in a bounded2048-entry queue; one owner-thread server END batch admits at most64anchors per native worldtick, then persists once before physical removals. Queue saturation defers excess attempts; persistent cooldown admission lets subsequent attempts enter as capacity drains. The bounded shutdown flush checkpoints remaining admitted work. The final performance stage should still measure large simultaneous sieges.

The existing starter() calls `LegacyDefense.placeStarterShelter(this)`. Before claiming delivery, it searches deterministic offset rings (step 8, radius 64) within already loaded chunks for a safe 7x7 site. The exact wasteland natural palette, eight-deep solid substrate, bounded relief, no tile entities and native HBM footprint exclusion prevent destructive placement; no candidate forces chunk loading. It sets the native world spawn to the selected center before the durable NONE -> CLAIMED checkpoint and physical edits. It builds V1 floor/walls/roof with bounded foundations, a paired door, roof hatch+ladder, glowstone, and a shared chest with 6 relays/16 dirt/8 saplings, then checkpoints DELIVERED. It never retries a partial CLAIMED delivery. Existing protectedAt/activeTicks grants the first 3 active hours around the selected physical spawn. Existing delivered worlds receive no second shelter.

Language snippets are in legacy/defense/lang/{en_us,ru_ru}.lang for root to merge into shared assets. Recipe source legacy/defense/recipes.json, generator tools/legacy_defense_recipes.py, packaged script legacy/pack/scripts/dead_earth_defense.zs. V1 inventory-grid shapeless uses vanilla iron shape+HBMsteelplate+HBMscrewdriver.anyDamage().reuse(). V2 consumesV1+4steelplates+2titaniumingots; V3 consumesV2+4titaniumplates+4tungsteningots. Native IDs and CraftTweaker reuse() were inspected in pinned jars.

Deferred assertions: `DefenseChecks.main` pure HP/cooldown/reload/bounds, and `DefenseProbe.run(runtime,world,player,x,y,z)` in a loaded fixture outside grace. Physical probe includes SRP writes, free door opening, shared halves, disk reload, the actual ESM dig task, native player harvest+drops and a real ordinary explosion. Tests/game were intentionally not run during implementation.
