# Раннее хранение перед AE2

Пользователь: лёгкий мод, поиск по сундукам, доступная HBM-прогрессия;
хранение не должно становиться сложностью. Отдельный SRP-форк.

Выбор: Simple Storage Network вместо EZStorage (нужна сеть существующих
сундуков, а не своё центральное хранилище). Tom's Storage не выбран:
у текущего проекта нет выпуска 1.12.2.

Доступ после первых железных пластин; без стали, схем, драгоценных камней,
энергии и Nether для основных функций. Сталь только для необязательного пульта.
Точный бюджет и инструкция — ../README.md. Данные рецептов — recipes.json.
Металлургия HBM сохраняется. Пользователь просил проверки после всех изменений:
сначала данные/сборщик/документация, затем единый прогон и отдельный тестовый мир.

Изменённые рецепты полностью заменяют нативные для тех же outputs,
включая только metadata 0 у remote. Остальные пульты не удешевляются.
ProjectE не может вычислить EMC готовой технологии из дешёвого рецепта.

Проверить в конце: удаление старых рецептов, реальный выход 32/8,
доступность plate_iron/plate_steel именно в закреплённом HBM,
поиск/изъятие/возврат в двух сундуках без дюпа, ручной крафт в Request Table,
отключение кабеля, сохранение/загрузка, отсутствие OV/SC/Mutationcraft
в целевом профиле и полное отсутствие секретов/миров в архиве.
