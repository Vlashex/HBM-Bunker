# Компактная ферма деревьев

Добавлен **Bonsai Trees 1.1.4-b170** для Forge 1.12.2 — один JAR около 643 KiB,
без обязательных дополнительных библиотек.

- Горшок для дерева: **5 комков глины + 2 железные пластины HBM**.
- Автогоршок для дерева: **горшок + обычная воронка**, бесформенный рецепт.
- Земля и саженец устанавливаются правым кликом. Оставьте воздух над горшком.
- Обычный горшок срубается топором после роста.
- Автогоршок ставится непосредственно над сундуком или другим совместимым
  контейнером и сам собирает урожай.

Базовое время роста — штатные 600 тиков (30 секунд при 20 TPS); тип дерева
и почва могут менять длительность и шансы добычи. Энергия не требуется.

В **config/bonsaitrees/settings.cfg** включено
**waitForEmptyItemBuffers=true**: заполненный или отсутствующий контейнер
приостанавливает следующий автосбор, уже полученные ресурсы сохраняются
в буфере горшка. Разрешённая добыча и вероятности остаются нативными Bonsai.

В общий финальный native-прогон добавлен BonsaiProbe: настоящие рецепты,
расход земли/саженца через клики, рост, рубка топором, накопление добычи без
контейнера и точный экспорт в настоящий сундук. В изолированном тесте
временно сокращаются только официальные native тайминги, затем значения
восстанавливаются; progress и предметы добычи вручную не устанавливаются.
Probe вызывает native ITickable напрямую и отдельно проверяет, что
установленные горшки зарегистрированы для обычного тиканья мира.
Это ускоренная функциональная проверка, не нагрузочный тест.

Официальный файл:
[CurseForge 2846217](https://www.curseforge.com/minecraft/mc-mods/bonsai-trees/files/2846217).
