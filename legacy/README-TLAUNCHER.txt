DEAD EARTH SRP (1.1.1) — Minecraft 1.12.2 / Forge 14.23.5.2860 / Java 8 x64

1. Создай НОВУЮ папку игры для форка. Не используй папку текущей 1.21-сборки.
2. Распакуй этот ZIP: папки mods, config и scripts должны лежать прямо в новой папке.
3. Установи Java 8 x64. В TLauncher выбери её javaw.exe и выдели 4096 МБ памяти.
   Более новая Java для этой старой Forge-сборки не подходит.
4. Запусти INSTALL-FORGE.bat. Он откроет официальный установщик точной Forge 2860.
   Если Java 8 не найдена, задай DEAD_EARTH_JAVA8 полным путём к её java.exe.
   В установщике выбери Install client и папку, где TLauncher хранит версии.
5. В TLauncher выбери установленный Forge 1.12.2-14.23.5.2860, а папкой игры
   укажи НОВУЮ папку с распакованными mods/config/scripts. Запусти игру.
6. Адрес отдельного SRP-сервера добавляется вручную. К серверу исходной сборки
   1.21.1 этот клиент не подключится.

В архиве нет сохранений и аккаунтов. ИИ и админка работают на стороне сервера:
друзьям не нужны Docker, Python и модели.

Статус: V1 Stable. Финальный Forge-прогон, настоящий перезапуск, клиент OpenGL
и Compose E2E пройдены. Это функциональная проверка, без обещания длительной
полевой стабильности. Страница выпуска и контрольные суммы архивов:
https://github.com/Vlashex/HBM-Bunker/releases/tag/srp-v1.1.0
