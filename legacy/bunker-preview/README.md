# Локальная примерка стартового бункера

Три варианта для Minecraft1.12.2, без изменения StarterShelter или установленного сервера:

- **A, КПП-17:** наземный вход7×7 и подземное убежище15×16.
- **B, Узел-6:** павильон9×7, основной подземный зал и техническое крыло; габарит18×20.
- **C, Редут:** полузаглублённый верх11×9 с земляными бортами и подвал15×15.

В каждом есть пешая лестница, жилые места, рабочая зона, общий стартовый запас и аварийный люк. Это варианты для визуальной оценки; в игровой кампании будет установлен один выбранный вариант с однократной выдачей запаса.

`tools/bunker_preview.py` строит раскладки и создаёт собственный клиент в новом каталоге work/bunker-preview-*. Официальные библиотеки, assets и natives читаются из подготовленного изолированного клиента. Аккаунты Prism не читаются. Мод Preview.java устанавливается только в этот клиент; серверные сборщики его не включают.

Мир открывается автоматически в одиночном творческом режиме. Проверяются маркеры каталога и мира, границы/число блоков, существование нативных блоков, сундуков и указателей. Геометрия размещается порциями по512 блоков за тик. После готовности ставится квитанция; повторный запуск не перестраивает мир поверх правок пользователя. Повторное нажатие запуска не создаёт второе окно.

Подготовка: `python -m tools.bunker_preview prepare --source-client work/<owned-interactive-client> --javac <jdk>/bin/javac.exe`.
Проверка путей: `python -m tools.bunker_preview layout-check`.
Запуск: `python -m tools.bunker_preview launch --directory work/<bunker-preview-directory> --java8 <java8>/bin/java.exe`.

Это локальные прототипы: до выбора пользователя никакой установки на сервер или выпуска релиза.
