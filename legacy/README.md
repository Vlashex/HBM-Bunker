# DEAD EARTH SRP — локальный форк 1.12.2

База исходников: DEAD EARTH 5.5.3 (`d5425ab`). Ветка `fork/srp-1.12.2`.
Рабочая сборка 1.21.1 и её сервер остаются отдельными.

**Готовится отдельный порт. Это ещё не полный релиз SRP-сборки.**
На этом этапе `storage/` — самостоятельный срез раннего хранения.
Старые корневые pack/, metadata/, mods/dead-earth/ и tools/release.py
содержат исходники современной сборки; они не устанавливают этот срез.
Не копировать в Minecraft 1.12.2 JAR из современного pack.

## Решения форка

- Minecraft 1.12.2 / Forge; OV и Mutationcraft исключаются из целевого состава.
- Новые враги: оригинальный SRP и Epic Siege; полный подбор версий ещё впереди.
- SecurityCraft исключается из целевого состава. Материалы и оборона — HBM;
  собственные V1/V2/V3, grace period и адаптеры требуют отдельного переноса.
- ИИ/админка сохраняются как исходники; игровой мост 1.12.2 ещё не реализован.
- Остальные замены современных модов не одобрены автоматически этим срезом.
- Текущий мир 1.21.1 не является миром для этого форка.

## Раннее хранение

Выбран Simple Storage Network 1.12.2-2.0.1 (447132 байта, без обязательных
библиотек самого SSN). CraftTweaker позволяет менять рецепты конфигом.
HBM Community Edition 2.6.1.0 закреплён для данного среза; не смешивать
его с Extended/Reloaded или текущим NeoForge HBM.

Канонические рецепты: `storage/recipes.json`. Сборщик создаёт из них `.zs`.

| Компонент | Материалы | Выход |
|---|---|---|
| Master | 1 железная пластина HBM, сундук, редстоун, 2 доски | 1 |
| Request Table с поиском и ручным крафтом | верстак, стекло, 2 доски, кабель | 1 |
| Кабель | 1 железная пластина HBM, 6 железных самородков, 2 стекла | 32 |
| Подключение сундуков | 2 кабеля, сундук, 2 железных самородка | 8 |
| Пульт, необязателен | 2 стальные пластины HBM, стекло, редстоун, кабель | 1 |

Сеть не требует энергии, дисков, процессоров, кварца, алмазов или похода
в другое измерение. Базовый комплект: 2 железные пластины HBM,
8 железных самородков, 1 редстоун, 3 стекла, 4 доски,
2 сундука и верстак; сами сундуки для вещей добавляются отдельно.
Получаем master, терминал, 8 подключений и 29 оставшихся кабелей.
Рецепты металла не облегчаются; готовые сетевые компоненты не получают EMC.
Ограничения заданы штатным legacy-конфигом ProjectE/custom_emc.json (EMC=0).
При расширении сборки объединять entries с общими ограничениями, не затирать их.

## Как пользоваться

1. Соединить Master, Request Table и Storage Link Cables обычным кабелем.
2. Storage Link Cable поставить к каждому сундуку/ящику, который нужен в сети.
3. Открыть Request Table: общий список, поиск и ручной крафт берут предметы из сундуков.
4. Один Master на связанную сеть; держать её в прогруженных чанках.
   Не подключать контейнеры с неизвестным отложенным лутом.
5. Для массового автоматического крафта и развитой логистики остаётся AE2.

Предметы хранятся в подключённых контейнерах. SSN не превращает их в диски.
В стартовом складе не нужны импорт/экспорт кабели: они относятся к автоматизации.

## Сборка отдельного профиля

Из корня форка (Python 3.11+):

```powershell
python tools/legacy_storage.py fetch
python tools/legacy_storage.py build
python tools/legacy_storage.py check
```

Prism ZIP в `dist/DEAD-EARTH-SRP-Early-Storage-0.1.0-Prism.zip` —
изолированный профиль проверки хранения, не полный перенос сборки.
Для серверного оверлея использовать ZIP `...-Server-Overlay.zip`,
загрузчик Forge установить отдельно по `metadata/runtime.json`.
Не распаковывать поверх текущего сервера/мира.
