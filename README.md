# HBM Bunker

**DEAD EARTH v2 · `2.0.1` · Minecraft 1.21.1 · NeoForge 21.1.262 · Java 21**

Сборка для выживания в бункере: HBM составляет основу производства,
Overgrown Vegetation захватывает мир, Mutationcraft добавляет заражение,
Improved Mobs усиливает мобов, Outpost Zero и SecurityCraft дают оборону.
Растения, сита и автоматизация сокращают ручной сбор ресурсов.

Это исходный репозиторий конфигурации сборки. В нём зафиксированы рецепты,
конфиги, точные версии модов, инструменты упаковки и результаты проверок.
MVP соответствует игровому содержимому ранее собранной **HBM Bunker Easy 1.2**.
Версия собственного патча остаётся **1.2.0**; новое имя версии обозначает
первый релиз проекта под Git. Игровой баланс при переносе не изменён.

## Что входит в MVP

- 28 внешних модов и собственный патч HBM Easy Balance: всего 29 JAR.
- Металлургия HBM и смешанные рецепты; закрыты дешёвые обходы стали и пластин.
- Mystical Agriculture + Botany Pots и Ex Deorum с дополнительными рудами HBM.
- RFTools Utility для раннего автокрафта, AE2 для хранения и заказного крафта.
- ProjectE: EMC для 92 базовых ресурсов; готовые технологии исключены.
- Just Hammers для раннего 3×3; Mining Gadgets развивается до 5×5 и 7×7 через HBM.
- Charging Gadgets для ранней зарядки лазера от угля.
- Книги Эффективности до X, Удачи до V, Прочности до V и Silk Touch I.

Подробности: [баланс](docs/BALANCE.md), [релиз](docs/releases/0.1.0-mvp.md),
[известные ограничения](docs/KNOWN-ISSUES.md), [история](CHANGELOG.md).

Следующее направление — **PROJECT DEAD EARTH**: постъядерная кампания,
циклы жары и пепельной зимы, две биосферы и ограниченный локальный ИИ-режиссёр.
Подготовлен [технический roadmap](docs/DEAD-EARTH-ROADMAP.md) для кооператива
2–6 игроков. [Первый срез Foundation](docs/DEAD-EARTH-FOUNDATION.md) реализован
отдельным модом. Предварительный выпуск включает координатор и
[Expeditions](docs/DEAD-EARTH-EXPEDITIONS.md): наблюдения и первую станцию связи.
Добавлен [первый MCP-мост](docs/DEAD-EARTH-MCP-BRIDGE.md) с семью ограниченными
инструментами и комплектом Python gateway. [Радиокаталог](docs/DEAD-EARTH-RADIO.md)
добавляет три варианта сообщений обнаруженных станций. [Климатические часы](docs/DEAD-EARTH-CLIMATE-CLOCK.md)
хранят цикл и прогноз; в v1 добавлены физическая погода, сезонные эффекты игрока,
огонь/лёд и адаптеры биосфер. Выбор событий нейросетью ещё не реализован.
Исходный ZIP MVP остаётся без координатора.
См. [текущий выпуск](docs/releases/2.0.1.md), [сезоны](docs/DEAD-EARTH-SEASONS.md) и
[результаты проверки климата](docs/DEAD-EARTH-CLIMATE-VERIFICATION.md).

## Установка для игры

1. Получи `dist/HBM-Bunker-2.0.1-Prism.zip` для отдельного тестового профиля
   либо прежний `dist/HBM-Bunker-0.1.0-mvp-Prism.zip` для исходной версии.
2. В PrismLauncher: **Добавить экземпляр → Импорт**, выбери ZIP.
3. Используй Java 21. Профилю назначено 6 ГБ памяти.
4. Запусти профиль и создай обычный мир. Minecraft и библиотеки докачает PrismLauncher.

Существующий профиль `HBM-Bunker-Easy-1.2-Prism` можно продолжать использовать:
этот MVP не меняет его сохранения или файлы. Импорт MVP создаёт отдельный профиль.

## Сборка из исходников

Для упаковки нужен **Python 3.11+** без сторонних библиотек.
Для запуска MCP gateway нужен отдельный **Python 3.12** и зависимости из `director/`.
Команды выполняются из корня репозитория. На Windows `python` можно заменить на `py -3`.
Для alpha сначала собери `mods/dead-earth/` с Java 21; артефакт должен соответствовать
`metadata/own-mods.lock.json`. JAR не хранится в Git. Изменение собственного кода
требует нового хеша и проверки перед упаковкой.

```sh
python -m unittest discover -s tests -v
python tools/release.py check
python tools/release.py fetch
python tools/release.py build
```

`fetch` скачивает зафиксированные версии с URL из `metadata/mods.lock.json`
и проверяет размер и SHA-256 каждого JAR. Если файл недоступен или отличается,
сборка останавливается; автоматической подмены новой версией нет.
Для нестандартного хранилища сертификатов доступен `--ca-bundle PATH`.

Если уже есть прежний проверенный ZIP, можно заполнить кеш без сети:

```sh
python tools/release.py import-cache ../HBM-Bunker-Easy-1.2-Prism.zip
python tools/release.py build
```

Результат — Prism ZIP, JAR собственного патча и `SHA256SUMS.txt` в `dist/`.
Порядок файлов, даты и параметры ZIP фиксированы: одинаковые входные файлы
и версия Python/zlib дают одинаковые архивы. Кеш и готовые архивы исключены из Git.

## Где менять сборку

| Путь | Назначение |
|---|---|
| `pack/patch/` | Основной источник рецептов, тегов, зачарований и данных патча |
| `pack/config/` | Конфиги, включая ограничения EMC ProjectE |
| `pack/mmc-pack.json` | Компоненты профиля PrismLauncher |
| `metadata/mods.lock.json` | Фиксированные версии, URL и контрольные суммы внешних модов |
| `metadata/emc-whitelist.json` | Справочный список разрешённых ресурсов и цен |
| `metadata/sieve-drops.json` | Справочный список дополнительных рецептов сит |
| `release.json` | Версия релиза, платформы и собственного патча |
| `tools/release.py` | Проверка входных данных, загрузка и упаковка |
| `tests/` | Проверки инструмента упаковки |
| `verification/mvp/` | Сохранённые результаты игровых проверок исходного MVP |
| `docs/ROADMAP.md` | План следующих этапов |

Справочные списки обновляются вместе с исходными рецептами. Сами рецепты
сборщик берёт непосредственно из `pack/patch/`, без старых генераторов.
Для нового изменения см. [CONTRIBUTING.md](CONTRIBUTING.md).

## Проверки и статус

На исходной сборке 1.2 ранее проверены: 47 прежних рецептов, 75 проверок
добычи/книг/обходов, 8231 значение EMC, 48 рецептов сит, автосбор горшка,
автокрафтер RFTools и 4096 реальных разрушений руды плоскостями AE2.
Удача III/V и Silk Touch работают на 32 проверенных видах руд HBM.

```sh
python tools/release.py check-evidence
```

Эта команда проверяет **сохранённый отчёт**, а не запускает Minecraft заново.
Тесты Python также не заменяют игровую проверку. Полный dev-клиент alpha уже
подключался к серверу и получал сигнал; обычный импорт и запуск ZIP в Prism
ещё не подтверждены.

В Git нет Minecraft, модов третьих сторон, миров, учётных записей или кешей.
Источники внешних модов перечислены в lock-файле; см. [THIRD-PARTY.md](THIRD-PARTY.md).
