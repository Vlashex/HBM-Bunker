# Локальный запуск DEAD EARTH

Дважды нажми start-dead-earth.bat в корне репозитория: запустятся уже настроенный сервер, Docker с CPU-моделью и live-режиссёр. Повторный запуск при работающем экземпляре сообщает его адрес и не создаёт второй сервер.

- start-dead-earth.bat status — состояние без запуска.
- start-dead-earth.bat stop — запросить остановку ИИ и сохранение/остановку мира.

BAT использует существующий локальный supervisor в соседней папке Dead-Earth-Server-3.2.0 и его deployment.json. Название папки осталось от 3.2.0: игровой состав релиза v4 идентичен. Мир, моды и профили не перезаписываются. Это точка запуска для текущего ПК; автоматическая установка на чистом ПК остаётся отдельной задачей.
