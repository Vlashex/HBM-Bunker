# DEAD EARTH SRP 1.1.3

Minecraft 1.12.2 · Forge 14.23.5.2860 · Java 8 x64.

Выпуск основан на стабильном 1.1.0 и проверенных исправлениях. Новая система
разрушения и HP материалов из нестабильных 1.1.1/1.1.2 не включена.

## Изменения

- Молоты 5×5 и 7×7 при проходке стены сохраняют пол на уровне ног.
- Исправлен SRG-вызов климатического эффекта, вызывавший ошибку func_180142_c.
- V0id’s Smart Backpacks 1.0.6: магнит, подбор и мусорный модуль с белым списком.
  Рецепты используют HBM. Улучшения рюкзака сохраняют содержимое и модули.
  Рецепты дробления и шести генераторов отключены; технологии не имеют EMC.
- Обычная и очищенная вода складываются по 64; зелья остаются по одному.
- Сырьё для сит и сжатые формы не имеют EMC. Земля и листья — 1 EMC за
  обычный блок, сжатие пропорциональное; булыжник сохраняет прежний EMC.
- Обнаружение сквозь блоки ограничено 16 блоками. Принятие попыток
  естественного спавна — 75%; обычные враждебные мобы не спавнятся при свете 8+.
  У SRP сохраняются нативные правила освещения и лимиты 20 + 2 на игрока.
  InControl устанавливается только на сервер; разрешающих SRP-правил нет.
- Исправлена воспроизводимость сборки: недостающие compile-only API заглушки
  теперь входят в исходники, но не в игровой JAR.

## Установка

Prism: импортировать архив Prism. TLauncher: установить Forge 2860 под Java 8
и распаковать отдельный архив TLauncher в папку профиля. Для подключения
друзьям нужен тот же клиент 1.1.3. Серверный архив запускается штатным Compose.

Перед обновлением существующего сервера остановите его с сохранением мира
и сохраните копию. Секреты, миры, аккаунты и веса моделей в архивы не входят.
Файлы текущего мира и его активное время не сбрасываются. Для собственных
изменённых конфигов используйте сравнение перед заменой.

## Проверки

Результаты финальных проверок и их ограничения фиксируются в
`verification/srp-release-1.1.3/summary.json`. Проверка не заменяет длительную
кооперативную игру; производительность в этом срезе не измерялась.
