# HBM Bunker 0.1.0-mvp

Дата: **16 октября 2026**. Статус: **MVP, предварительный релиз**.
Git-тег: `v0.1.0-mvp`. Основа — проверенная сервером сборка Easy 1.2.

## Результат

Первая версия проекта под Git: HBM, захватывающая растительность, заражённые мобы,
оборона бункера, облегчённая добыча и автоматизация. Состав зафиксирован:
28 внешних модов плюс собственный патч 1.2.0 на Minecraft 1.21.1 NeoForge 21.1.262.

Новые инструменты развиваются через материалы HBM до 7×7; книги доступны до
Эффективности X, Удачи V и Прочности V. Руды с Silk Touch можно обрабатывать
плоскостью аннигиляции AE2 с Удачей. Баланс при оформлении MVP не менялся.

## Артефакты

- `dist/HBM-Bunker-0.1.0-mvp-Prism.zip` — импорт в PrismLauncher.
- `dist/hbm-easy-balance-1.2.0-neoforge-1.21.1.jar` — собственный патч.
- `dist/SHA256SUMS.txt` — контрольные суммы обоих файлов.

Для игры: импорт ZIP, Java 21, 6 ГБ RAM. Для сборки из исходников:
Python 3.11+, команды из README. Готовые бинарные файлы не входят в Git.

## Проверки

Сохранены результаты испытаний исходной Easy 1.2 от 16.10.2026:
47 проверок прежних рецептов, 75 проверок новых рецептов/наковальни/зарядки,
8231 значение EMC, 48 рецептов сит, работа горшка и автокрафтера RFTools.
Для 32 руд HBM проверены четыре режима по 32 блока: 4096 разрушений
реальными плоскостями AE2; Удача III/V и Silk Touch дали ожидаемый результат.

Упаковка MVP дополнительно проверяется локальными тестами инструмента,
сверкой всех внешних JAR с lock-файлом и сравнением содержимого с исходной сборкой.
Это не новый запуск игры. [Известные ограничения](../KNOWN-ISSUES.md)
включают неподтверждённое главное меню клиента и отсутствие полного игрового прогона.

## Существующие профили

Профиль Easy 1.2 и пользовательские сохранения остаются на месте.
Перенос в Git не требует обновлять игровой мир. Импорт MVP создаёт
отдельный профиль с тем же игровым содержимым; поддержка последующих
миграций будет описываться в соответствующих релизах.
