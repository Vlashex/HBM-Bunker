# DEAD EARTH SRP 1.1.1 — инструменты и удобство

- Молоты 5×5/7×7 проходят стену от уровня ног, сохраняя пол; добыча и расход прочности HBM сохранены.
- Simply Backpacks с фильтрами и подбором, Simple Magnets и Trash Cans; доступные рецепты через HBM.
- Просеиваемое сырьё и его сжатые формы больше нельзя получать через EMC. Булыжник сохраняет EMC=1.
- Включены накопленные исправления админки, генерации, сит и конфигурации после 1.1.0.

Epic Siege остаётся в составе. Полная собственная замена, новые HP материалов и фазовый урон из обсуждения ещё не входят в этот выпуск.

Проверено: 119 legacy unit-тестов; нативный Forge-прогон функционального кода до изменения номера версии — 22 группы / 316 проверок, 138,22 секунды. Геометрия молотов проверена настоящим HBM. Два известных сбоя исторического modern-упаковщика к SRP-архивам не относятся. Реальный инференс и клиентские визуальные изменения этим прогоном не проверялись.

Установка: Prism ZIP импортируется как экземпляр; TLauncher ZIP содержит клиентский overlay и INSTALL-FORGE.bat. Minecraft 1.12.2, Forge 14.23.5.2860, Java 8 x64. Серверный overlay запускается через штатный Docker Compose. При обновлении сохраняйте существующий мир и пользовательские настройки.
