# DEAD EARTH 5.0.0

Мягкий старт кампании, безопасный стартовый бункер и лёгкий клиент.
Minecraft 1.21.1 / NeoForge 21.1.262 / Java 21; координатор 4.0.0.

## Изменения

- Первые 60 минут активной кампании: сложность 0.1 → 1 по quadratic ease-out.
  Затем за 5 минут плавно подключается адаптивная сложность команды.
- Развитие Mutationcraft дополнительно замедлено до ×0.25. Сезон и общая
  сложность продолжают влиять на развитие; стадии и очки не сбрасываются.
- Первые 180 минут кампании исходная конструкция стартового бункера защищена
  от разрушения, включая параллельный snapshot-взрыв HBM. Монстры не могут
  появляться, проходить и телепортироваться внутрь. Двери и контейнеры работают.
- Inventory Sorter, Jade, Block Outline Customizer; Sodium, Iris, FerriteCore
  и ModernFix. В клиенте 35 внешних и 2 собственных JAR, на сервере 32 + 2.
- MakeUp Ultra Fast 9.5g: лёгкий профиль с тенями по умолчанию, дополнительные
  варианты без теней и без шейдера. Шейдер добавляет нагрузку GPU.
- Все коэффициенты старта, длительность защиты и список разрешённых машинных
  меню находятся в серверном `config/dead-earth-server.toml`.

## Установка и сохранения

Новый клиент импортируется из `HBM-Bunker-5.0.0-Prism.zip` отдельным профилем.
Для TLauncher подготовлен отдельный архив с официальным установщиком NeoForge,
папкой `game` и инструкцией. Не смешивайте версии модов. Клиенту рекомендуется
6 ГиБ памяти; графические пресеты находятся в `client-presets/`.

Перед обновлением сервера остановите его штатно и сохраните копию мира.
Замените собственный координатор 3.3.0 на 4.0.0, добавьте четыре общих мода:
Inventory Sorter, Jade, FerriteCore и ModernFix. Sodium, Iris, рамка блока
и shaderpacks на сервер не устанавливаются. Патч рецептов остаётся 1.2.0.

Существующий возраст кампании сохраняется: первые 1/3 часа не начинаются заново
после обновления. Защита старого бункера включается после ограниченной проверки
его родного OutpostZero-плана и загруженных блоков; повреждённые либо неизвестные
SavedData не заменяются. Новый мир не требуется. Работающая установка и её мир
не заменяются автоматически выпуском архива.

По умолчанию сортировка работает в инвентаре и ванильных контейнерах. Модовые
машинные меню отключены для сортировки и переноса колёсиком, чтобы сохранить
служебные слоты. Разрешение проверенного меню — точный ID в
`convenience.sortingAllowedModMenus`, без wildcard.

## Проверки

164 Java unit, 85 игровых GameTest и 16 тестов упаковщика прошли. Свежий обычный
сервер принял настоящий клиент с готовым JAR координатора и всеми 37 JAR.
MakeUp работал через IrisRenderingPipeline: fallback=false, shaderError=false,
GL error=0. Таймеры проверены на границах значений, без ожидания часа или трёх
часов. Отдельные тестовые процессы завершены штатно.

[Свидетельство](../../verification/v5/checks-5.0.0.json). Сравнение FPS,
исчерпывающий визуальный просмотр всех эффектов и полный GUI TLauncher не
проводились. Computer Use и скриншоты не использовались.
