# DEAD EARTH 5.4.0 — фазы эволюции

Координатор 4.3.0 добавляет шесть управляемых фаз Mutationcraft: последовательные
открытия существ, индивидуального развития и способностей; пауза развития без
игроков; состав волн по текущей фазе. В админке появились прогресс, история и −/+.
Подробности и конфиг: [Эволюция паразитов](../DEAD-EARTH-EVOLUTION.md).

Старый мир переносится один раз по активным часам кампании с migrationRate=0.25.
Нативное время, постройки, инвентари и уже существующие существа сохраняются.
Отсутствующее обязательное/повреждённое сохранение не запускает новый пересчёт.
Перед установкой сохраните резервную копию всей папки мира; новый checkpoint
нельзя безопасно откатывать простым удалением файла эволюции.

Состав: 38 JAR клиента/36 сервера; новый собственный JAR `dead-earth-4.3.0.jar`,
патч рецептов 1.4.0 и внешние моды прежние. Шейдеров/Iris нет. Обновлять собственный
JAR и конфиги следует согласованно на клиенте/сервере при остановленной игре.

Это локальный выпуск. Публичные архивы 5.3.0, рабочий сервер и установленные
профили пользователя этим срезом автоматически не заменяются.
