# DEAD EARTH 5.3.0

Защитные стены, двери и люки трёх классов для Minecraft 1.21.1 /
NeoForge 21.1.262. Координатор 4.2.0; патч баланса 1.4.0 отключает старый рецепт steel.
Сторонние моды и шейдеры не менялись: 39 JAR клиента, 36 JAR сервера.

- V1/V2/V3 имеют 1000/2000/8000 HP. V1 сохраняет вид стали текущего бункера
  Outpost Zero, V2/V3 темнее. Дверь имеет общие HP двух половин.
- V1 крафтится в сетке с Reinforcer SecurityCraft, инструмент возвращается.
  Улучшения требуют предыдущий класс и пластины HBM; двери/люки — свои стены.
  Для повторяемого AE2 pattern рекомендуется неизнашиваемый Reinforcer lvl3.
- V3 защищён от Putrid/Hook, конверсии леса и поддержанных прямых замен.
  Известные копатели и взрывы расходуют HP; ядерный иммунитет не добавляется.
  Коэффициенты находятся в `config/dead-earth-defense.toml`.
- Точный старый `outpostzero:steel_block` заменяется на V1 в новых шаблонах
  и ограниченной миграцией загруженных старых чанков. Старый registry ID
  сохраняется. SecurityCraft других типов не удаляется; срок защиты стартового
  бункера не продлевается. Журнал записывается до замены.
- Исправлена ошибка обхода entity sections при удалении существующих монстров
  из защищённого бункера: сначала собираются цели, затем выполняется discard.

Новый мир не обязателен. Клиент и сервер нужно обновить согласованно из-за новых
registry IDs. Основная работающая установка автоматически не обновляется.

Проверено: 187 Java unit и все 111 GameTest в отдельном новом мире. Проверяются
реальные native методы заражения, разрушения, взрывов, крафты, сохранение HP,
верхняя половина двери, изоляция destructive scopes, миграция и AE2 pattern API.
Отдельный обычный сервер и настоящий клиент успешно соединились: девять
предметов и все 387 состояний имеют модели и текстуры, Iris/MakeUp активен без
fallback и ошибок OpenGL. В сохранённом исходном снимке нового бункера —
3744 собственные стены V1 и ноль legacy steel, срок защиты 216000 тиков.
Тестовые процессы закрыты штатно, снимки экрана не делались.
