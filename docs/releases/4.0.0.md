# DEAD EARTH 4.0.0

Переоформление готовой 3.2.0 в релиз v4 без изменения игровых JAR, рецептов и конфигов. Собственный координатор сохраняет версию 3.2.0. Работающий сервер и клиент не обновляются и не перезапускаются.

Локальная версия для Minecraft 1.21.1, NeoForge 21.1.262 и Java 21.

## Изменения

- Пустошь: камень, инертный пепел и обломки, частые мелкие/редкие крупные кратеры, голые стволы и мутный цвет обычной воды.
- Все постройки HBM, руды и карта биомов сохранены; наземные ванильные сооружения отключены точечно. Собственная генерация не добавляет радиацию.
- Каталог 15 интерактивных событий, 103 звуков и 48 следов; ветвления по действиям игроков, ограниченная очередь, расчёт давления от игроков и зон.
- CPU-модель выбирает из разрешённого сервером списка; MCP не получает произвольную консоль или координаты. Поддерживаются серверный fallback и журнал решений.
- Неоткрытый случайный loot пропускается при оценке зоны; живые выгруженные волны и незавершённые эффекты защищены от ошибочного повтора.

## Установка и совместимость

Импортировать `HBM-Bunker-4.0.0-Prism.zip` отдельным экземпляром PrismLauncher, Java 21, память клиента 6 ГБ. Клиент и сервер должны иметь одинаковый состав модов. ИИ запускается рядом с сервером, на клиенте Docker не требуется.

Для цельного ландшафта нужен новый мир. В существующем мире старые блоки сохраняются, новые чанки генерируются как пустошь и образуют видимую границу. `dead_earth:ash` требует сохранения мода в дальнейшем. Выпущенные миры и профили при установке этой версии не перезаписываются.

Настройки генерации: `config/dead-earth-worldgen.toml`, перезапуск для применения. Сезоны/баланс/режиссёр: `config/dead-earth-server.toml`. События: `config/dead-earth/director/catalog.json`. В сборке не меняются версии внешних модов и рецепты металлургии HBM.

## Унаследованные результаты 3.2.0

Для 4.0.0 повторные проверки и тесты не запускались по прямому запросу пользователя. Следующие результаты относятся к неизменённому игровому составу 3.2.0.

151 unit и 74 full-pack GameTest прошли; физически проверены HBM geyser/vault/barrel на инертной поверхности. Обычный отдельный сервер с новым миром успешно запущен; Prism-профиль с теми же 30 проверенными JAR подключился. CPU-режиссёр работает в режиме live. Итог в `verification/wasteland/release-checks.json`.

Нет измерения нагрузки на шесть одновременно играющих клиентов. CPU-модель ранее проверена вместе с настоящим клиентом; это не отдельный нагрузочный тест FPS во время каждого вывода модели.

В замёрзших океанах могут оставаться ледяные стенки нативных айсбергов под новой поверхностью; отдельной визуальной доработки этих биомов в 3.2.0 нет.
