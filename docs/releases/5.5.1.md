# DEAD EARTH 5.5.1 — переключатель ИИ в админке

Обзор → Модель и решения: **1 модель /2 модели**, применение без перезапуска
Minecraft и отдельный статус памяти критика. Выбор сохраняется между запусками.
Переход на single пропускает следующие этапы обсуждения и выгружает критика;
текущий запрос завершается в пределах своего таймаута. Возврат на dual
не загружает обе модели заранее: они работают последовательно по запросу.

Успех выгрузки подтверждается отсутствием закреплённого digest в `/api/ps`.
Основная модель защищена от ошибочного совпадения pin. Старые вкладки/повторы
не отменяют более новый выбор. При недоступном host/Ollama панель явно показывает
ожидание или неизвестное состояние, сохраняя выбранный режим.

Обновлены только Python director/admin, интерфейс и упаковка. Java4.4.0,
внешние моды, мир, игровые конфиги и рабочие веса прежние. Для применения
обновите оба Python-процесса admin/host; перезапуск Minecraft не нужен.
Локальный релиз автоматически не меняет установленный сервер/Prism/GitHub.
