# DEAD EARTH v1 — сезоны

Первый из трёх запрошенных этапов: лето/зима с погодой, визуальными эффектами,
воздействием на игрока, огнём/льдом и адаптерами двух биосфер.
Коэффициенты: зима паразиты1.8/лес0.25; лето паразиты0.5/лес1.5; затишье1.
Здоровье и урон паразитов тоже изменяются. Подробности и границы каналов —
[сезоны](../DEAD-EARTH-SEASONS.md).

Установка: импортировать HBM-Bunker-1.0.0-Prism.zip в отдельный экземпляр Prism,
Java21, 6ГБ памяти. Внешние моды и патч рецептов HBM не обновлялись. Новая система
температуры/погоды реализована внутри собственного мода без тяжёлых зависимостей.
Перед применением к ценному миру сделать резервную копию: летом обычный огонь
имеет последствия Minecraft. Установка автоматически в пользовательский профиль
не выполняется. Публичного GitHub-релиза нет — это локальная поставка.

Сохранения кампании alpha.4 читаются; дата начала и маркеры не сбрасываются.
Добавлены собственные сезонные блоки и модификатор maxHP существующих заражённых
мобов. Откат мода на alpha после появления этих блоков не поддерживается.

Проверено: 90 Java unit-тестов, 30 full-pack GameTests (17.47с), 13 тестов упаковки;
клиент, зимний рендер/переход на лето и сохранение часов после restart.
Подробности: [сводка проверки](../../verification/seasons-v1/README.md).
Автомат сложности и оценка зон запланированы соответственно для2.0.0 и3.0.0.
