# DEAD EARTH 4.2.0

Один общий стартовый запас для всей команды в стартовом бункере OutpostZero: 6 загрузчиков зон, 256 земли и по 4 саженца/ростка восьми обычных видов деревьев. Он добавляется к штатному луту первого подходящего сундука центрального модуля, открытого игроком. Другие игроки получают доступ к тем же вещам, а не новые комплекты.

## Механика и настройки

Квитанция сохраняется в мире; другие сундуки, входы, смерти и обычные перезапуски не выдают запас повторно. Переполненный сундук не расходует квитанцию; исходные вещи не удаляются. Неизвестные/повреждённые данные не заменяются новым состоянием. Проверка выполняется только при генерации лута, без постоянного сканирования бункера.

Количество загрузчиков, земли и саженцев настраивается в секции starter серверного dead-earth-server.toml. Изменение количества не пополняет уже выданный запас. [Полное руководство и ограничения](../DEAD-EARTH-STARTER.md).

## Установка и совместимость

Minecraft 1.21.1 / NeoForge 21.1.262 / Java21. Координатор 3.3.0. Внешние моды и рецепты HBM не менялись; новые моды не добавлены. Исправление кратеров4.1.1 включено.

HBM-Bunker-4.2.0-Prism.zip можно импортировать отдельным экземпляром. Для обновления существующей установки при остановленных клиенте/сервере замените прежний dead-earth JAR на dead-earth-3.3.0.jar в обоих mods; не оставляйте две версии одновременно. Текущий установленный сервер и профиль автоматически не обновлялись и не перезапускались.

Для новых миров запас доступен при первом открытии стартового сундука. В старом мире нужен ещё не раскрытый подходящий сундук: существующие открытые контейнеры не перезаписываются. При аварии между подтверждением квитанции и сохранением чанка возможна потеря запаса; повторять выдачу автоматически небезопасно. Старые квитанции не удаляйте ради повторного старта.

Загрузчики формируют зоны после размещения. Пересекающиеся области объединяются; для отдельных зон оставляйте между центрами загрузки минимум три чанка по горизонтальной оси.

## Проверки

- До реализации новый GameTest воспроизвёл отсутствие шести загрузчиков в нативном стартовом сундуке.
- 154 Java unit tests прошли, включая квитанцию для шести UUID, сериализацию и неизвестные/неполные данные.
- 76 full-pack GameTests прошли в новом мире run-gametest-starter-green-2 за31.72 секунды исполнения. Шесть подключённых тестовых игроков, восемь контейнеров, нативная таблица OutpostZero, нехватка места, запас целиком, повторное открытие, чтение квитанции новым DimensionDataStorage и пять следующих сундуков: суммарно6 загрузчиков, личная выдача0.
- Проверки сборщика и хеши архива выполняются отдельно. Свидетельство: verification/starter/checks-4.2.0.json.
- Визуальный GUI-прогон не проводился; Computer Use остаётся остановленным по просьбе пользователя.
