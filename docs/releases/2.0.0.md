# DEAD EARTH v2 — адаптивная сложность

Добавлены автомат сложности по статистике игроков и адаптивная скорость эволюции
паразитов/фаз развития леса. HP/урон монстров тоже регулируются. Календарь сезонов
независим от счёта; игровые настройки вынесены в серверный конфиг.
Подробности: [автомат сложности](../DEAD-EARTH-ADAPTIVE.md).

Импорт: HBM-Bunker-2.0.0-Prism.zip в отдельный профиль Prism, Java21, 6ГБ.
Внешние моды и рецепты HBM не изменились. Сохранения v1 читаются без сброса сезона.
Перед обновлением ценного мира нужна копия; откат климатической schema2 на v1 не поддержан.
Локальный релиз, без публичной публикации и автоматического изменения профилей.

Проверено: 99 Java unit, 39 full-pack GameTests (15.24с), 13 проверок упаковки;
нативное развитие обеих биосфер, настоящий клиент с синхронизацией нестандартных
настроек, миграция мира v1 и сохранение после restart.
[Сводка и ограничения](../../verification/adaptive-v2/README.md).
