# DEAD EARTH 4.1.0

Локальная админка ИИ: обзор кампании, графики давления/развития/ценности зон, журнал решений, очередь и архив исходов сценариев, состояние зон и интерактивный просмотр 15 событий. Фильтры по кампании, поиск решений, экспорт JSON. Панель только читает данные; цели, спавн, команды и генерация модели из браузера недоступны.

## Запуск

На текущем ПК: `start-admin.bat` из репозитория, http://127.0.0.1:8765 . Также `start-dead-earth.bat admin`. Minecraft и работающий ИИ не перезапускаются. `start-admin.bat status` проверяет панель, `start-admin.bat stop` останавливает только наблюдатель.

На другом ПК распакуйте `director/` и `start-admin.bat` из ZIP в отдельную папку. Из director запустите `admin.ps1 -ServerRoot 'C:/path/to/server'`. Подготовьте Python через setup.ps1 либо укажите его в deployment.json сервера. Каталог берётся из config/dead-earth/director/catalog.json сервера, если рядом нет исходников pack/. Импорт ZIP в Prism сам по себе не запускает сервер, Docker или панель.

Подробности: [руководство админки](../DEAD-EARTH-ADMIN.md).

## Данные и совместимость

- Игровой координатор 3.2.0, внешние моды, рецепты и генерация не менялись. Существующие миры и установленные профили сохраняются; повторный импорт клиента для работы панели не нужен.
- Журнал ИИ читается без изменений. Собственные графики и архив наблюдателя хранятся в director/runtime/admin.sqlite3 сервера. Старый журнал не содержит всех вариантов/времени: неизвестные поля не восстанавливаются вымышленно.
- Новые исходники host сохраняют кампанию/эпоху, время, контекст, варианты с весами, выбранный индекс и ID операции. Установленный host.py подготовлен для следующего штатного запуска; работающий процесс ИИ продолжает старый формат до перезапуска.
- Подробный внутренний ход рассуждений модель не записывает. Панель показывает фактический выбор и серверные оценки, допуск и подтверждённый исход.
- Наблюдения начинают накапливаться после старта панели; периоды отключений видны разрывами. Срок/объём ограничены: 7 суток, 20000 измерений, 10000 событий, 16 кампаний. В выборке до 500 решений, до 1000 исходов и 1000 наблюдений.

## Проверено

41 Python-проверка шлюза и админки, 13 проверок сборщика, source check. DOM-проверки пяти экранов, графиков, поиска, архивов, каталога и безопасного вывода текста. Реальный серверный мост и CPU-модель доступны панели; графики получают реальные измерения.

Независимое ревью: исправлены ложные разрывы после прореживания, выбор эпох из старого журнала и упаковка BAT. Все три замечания воспроизведены тестами до исправления. Свидетельство: verification/admin/checks.json.

Визуальная проверка браузера не завершена: сначала инструмент не смог определить URL, затем пользователь попросил остановить Computer Use. Игра/ИИ в рамках этого среза не перезапускались; повторные игровые тесты не выполнялись, поскольку игровые файлы не изменялись.
