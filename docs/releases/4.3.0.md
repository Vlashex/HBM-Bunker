# DEAD EARTH 4.3.0

Консоль Minecraft внутри существующей локальной админки: последние600 строк stdout/latest.log, обновление каждые2,5с, команды с / и без него, ответы, последние50 записей и подстановка истории стрелками. Вся история выводится текстом; игровые строки не выполняются как HTML.

## Установка

Обновите каталог director и start-admin.bat из этого выпуска. Остановите/запустите только админку через start-admin.bat stop / start. Игра и ИИ продолжают работать независимо. Откройте прежний адрес http://127.0.0.1:8765/#console .

Журнал доступен сразу. Для ввода команд выполните start-admin.bat console-setup, затем один обычный перезапуск Minecraft. Подготовка требует server-ip=127.0.0.1, свободного порта25575, создаёт случайный пароль в server.properties и резервную копию в director/runtime. Никакой пароль не вводится в браузере. Консоль не работает с публичной привязкой сервера.

Это пульт человека с правами серверной консоли. Набор MCP остаётся ограниченным; модель не получает execute_command. Подробности, размеры и обработка неопределённого исхода описаны в [руководстве](../DEAD-EARTH-ADMIN.md).

## Совместимость и проверки

Minecraft1.21.1 / NeoForge21.1.262, координатор3.3.0 из4.2.0. Игровые JAR/рецепты/конфиги мира в этом выпуске не изменяются. Импорт ZIP включает ранее выпущенные исправления кратеров и командного стартового запаса; текущая работающая установка автоматически на них не переводится.

48тестов director: RCON с настоящими TCP-сокетами, фрагментация/несколько пакетов, авторизация, потеря ответа, UUID после повторного открытия SQLite, HTTP Origin/nonce/валидация, ограниченный хвост/ротация/скрытие пароля, безопасная подготовка свойств. Также13тестов сборщика, source check, DOM-проверка шести вкладок с однократной отправкой/неопределённым ответом и синтаксический разбор PowerShell. Игровые тесты не повторялись: Java и состав модов не менялись. Визуальный GUI-прогон не проводился по действующему запрету Computer Use.

Живую команду на установленном Minecraft можно подтвердить после согласованного первого перезапуска с RCON. До этого интерфейс показывает причину недоступности ввода и работает как журнал.
