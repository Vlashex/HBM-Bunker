# HBM Bunker 0.2.0-alpha.4

Локальный предварительный выпуск от 2026-10-16. Minecraft 1.21.1,
NeoForge 21.1.262 / Java 21, прежние 28 внешних модов и патч 1.2.0,
собственный Dead Earth 0.2.0-alpha.4: всего 30 JAR.

Добавлены [климатические часы и прогноз](../DEAD-EARTH-CLIMATE-CLOCK.md).
Цикл: затишье с потеплением, жара, затишье с охлаждением, пепельная зима;
по два активных дня на шаг. Статус доступен оператору и через прежний MCP.
Уведомления переживают перезапуск без автоматического повторения.

Режим forecast_only: физической температуры, смены погоды, снега/льда и влияния
на биосферы пока нет. Модель ИИ не подключена. Рецепты/EMC не изменены.

Импортируй `HBM-Bunker-0.2.0-alpha.4-Prism.zip` в отдельный тестовый профиль Prism.
При первом добавлении в существующую кампанию новый климатический цикл начинается
от её текущих часов с подготовки CALM/WARMING; прошлые сезоны не симулируются.
Добавляется `dead_earth_climate.dat` schema1; прежние схемы остальных подсистем
не менялись. Повреждённые данные сохраняются без замены и отключают координатор.
Для отката/переноса своего мира используй резервную копию всего сохранения.
Пользовательские профили и миры не изменялись.

84 JUnit и 21 GameTest прошли. Полный восьмидневный круг проверен детерминированно;
две короткие клиентские сессии полной сборки проверили начальный шаг, уведомление,
часы и восстановление. Начальное сообщение после рестарта не повторилось.
См. [фактический отчёт](../DEAD-EARTH-CLIMATE-VERIFICATION.md).
Обычный импорт/запуск этого ZIP в Prism, 160-минутная погодная сессия и нагрузка
2–6 игроков не подтверждены. Это предварительный alpha-выпуск.
