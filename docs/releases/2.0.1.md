# DEAD EARTH2.0.1 — толстая зима

Покрытие из полного льда и снега постепенно нарастает сверху и по открытым
боковым поверхностям. По умолчанию:2 льда+1 снег сверху,1 лёд+1 снег по бокам.
Плавная карта высот меняется каждую зиму, редкие пики получают ледяные вершины.
При оттепели воздушное покрытие исчезает без затопления. Все параметры — в
серверном конфиге; внешний состав модов и рецепты HBM не изменились.

Импорт: HBM-Bunker-2.0.1-Prism.zip в отдельный профиль Prism, Java21,6ГБ.
Миры2.0.0 читаются. Новые блоки сохранений требуют2.0.1 или новее.
Локальный релиз, без изменения пользовательских профилей.
