# DEAD EARTH SRP 1.1.2 — сохраняемые HP строительных блоков

Выпуск следует за 1.1.1 и содержит отдельный патч прочности.

| Материал | HP |
|---|---:|
| Камень | 200 |
| Булыжник | 300 |
| Сжатый булыжник ×9 / ×81 / ×729 / ×6561 | 600 / 1200 / 2400 / 4800 |
| Бетон HBM | 4000 |
| Обсидиан | 8000 |
| Железобетон HBM | 10000 |
| Бункер V1 / V2 / V3, двери и люки | 6000 / 12000 / 48000 |

Добавлены 28 профилей обычных строительных блоков: также кирпич, древесина,
стекло и несколько грунтов. Повреждения обычных материалов сохраняются
по чанкам; ограничение кеша не ограничивает число повреждённых позиций мира.
Реле-осада, SRP/ESM-записи и обычные взрывы учитывают настроенные HP.
Избирательно разрешены строительные материалы HBM, машины и контейнеры
не включены в общий механизм.

Старые повреждения бункера переносятся пропорционально: половина старого HP
остаётся половиной нового. Миграция однократная, исходный журнал сохраняется
рядом как `.schema1.bak`. Для отката мода нужна совместимая копия данных мира.

Скорость обычной добычи игроком сохранена. Разборка/повторная установка всё
ещё сбрасывает повреждения: отдельный ремонт с расходом материалов пока
не реализован. Epic Siege остаётся в составе; собственная полная замена,
фазовая скорость разрушения и полная синхронизация его анимаций не входят
в этот быстрый патч. Число попыток ESM не равно числу взмахов или секундам.

Настройки: `config/dead-earth/material-hp.json`, включая `bunkerHitPoints`.
Требуется перезапуск сервера. Операторская проверка загруженного блока:
`/deadearth blockhp <dimension> <x> <y> <z>`.

Архивы: Prism, TLauncher и Server-Overlay. Minecraft 1.12.2, Forge
14.23.5.2860, Java 8 x64. При обновлении сохраняйте мир и свои настройки.

Проверено: 18 целевых unit-тестов; полный прогон в новом мире — 23 группы,
318 проверок, без ошибок рецептов; 27 проверок bridge/режиссёра/админки.
Генерация руды, вызванная поиском пути паразита, отдельно исключена из
враждебного урона. Проверка выполняется за несколько минут, без ожидания
игровых часов. Повторная визуальная проверка клиента и реальная генерация
текста моделью для этого патча не выполнялись.
