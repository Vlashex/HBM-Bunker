# DEAD EARTH 5.1.0

Постановка событий и визуальный конструктор сценариев в локальной админке.
Minecraft1.21.1 / NeoForge21.1.262 / Java21; координатор4.1.0.

Вкладка «Постановка»: выбор события/зоны, серверный расчёт бюджета, запуск и
отмена операции. Конструктор позволяет копировать события, добавлять звуки,
следы, волны и реакции игроков, сохранять черновики и публиковать новые графы
в библиотеку режиссёра. [Инструкция](../DEAD-EARTH-ADMIN.md).

Публикация проверяет граф, регистры, эпоху/ревизию и исходный файл; создаёт backup
и атомарно заменяет каталог. Активные операции сохраняют frozen-граф.
Квитанции записываются до отправки: uncertain не повторяется автоматически.
Произвольных команд в сценариях нет. MCP/модель новых прав не получают.

Включены три отдельных ранее подготовленных коммита оптимизаций:
[геометрия наледи, отчёты зон, worker JSON-снимков](../performance/README.md).
Операции с миром и обязательные checkpoint остаются на серверном потоке.

Для обновления нужен новый координатор4.1.0 и Python/HTML/CSS/JS админки.
Старый JAR удаляется только на остановленном сервере/клиенте. Сохранения и
возраст кампании продолжаются, новый мир не нужен. Библиотеки событий и
SQLite-журналы сохраняйте. Черновики можно готовить и на старом сервере,
но запуск и публикация потребуют штатного обновления и перезапуска Minecraft.

Проверки:180 Java unit и90GameTest в отдельном новом мире,59 Python-тестов,
два DOM-набора и16 тестов упаковщика. Сквозная проверка HTTP/RCON указана
в [новом отчёте](../../verification/admin-authoring/README.md). Проверка DOM выполняется без браузера;
визуальный осмотр и повторный графический прогон клиента не заявляются.
