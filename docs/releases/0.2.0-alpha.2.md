# HBM Bunker 0.2.0-alpha.2

Локальный предварительный выпуск от 2026-10-16. Minecraft 1.21.1,
NeoForge 21.1.262, Java 21. 28 внешних модов, HBM Easy Balance 1.2.0
и Dead Earth 0.2.0-alpha.2: всего 30 JAR.

Добавлен [первый MCP-мост](../DEAD-EARTH-MCP-BRIDGE.md): семь ограниченных
инструментов, наблюдение из кеша и постановка безопасного сигнала через серверную
очередь. Есть предварительная проверка, повтор по request_id, квитанции и отмена.
Мост выключен по умолчанию; оператор включает его в конкретном мире.

В ZIP включён `director/`: исходники stdio gateway, установщик и lock с хешами.
Нужен отдельный Python 3.12 Windows amd64. Нейросеть и автоматическое принятие
решений ещё не подключены; host MCP нужно настроить самостоятельно.

## Установка и сохранения

Импортируй `HBM-Bunker-0.2.0-alpha.2-Prism.zip` в отдельный тестовый профиль Prism.
Игровые ресурсы и библиотеки докачивает лаунчер. Для сервера используй свой
отдельный каталог с теми же 30 JAR и конфигами. Gateway необязателен для игры.

Формат кампании не менялся. Проверено восстановление текущего тестового мира
alpha.2; миграция произвольных пользовательских миров отдельно не проверялась.
Существующие профили и сохранения пользователя не менялись. Перед переносом
своего мира сохрани резервную копию.

## Проверки и ограничения

64 JUnit, 16 GameTest, 9 тестов gateway и 13 проверок упаковки прошли.
В полной сборке один dev-клиент получил единственный MCP-сигнал; отменённый
сценарий не исполнился. На повторном серверном запуске сохранились 602 активных
тика и квитанции, запрос со старой эпохой отклонён.
Подробности: [проверка MCP](../DEAD-EARTH-MCP-VERIFICATION.md).

Климат, разрушительные события, биологические атаки, память ИИ и модель отсутствуют.
Обычный импорт/запуск этого ZIP через Prism и нагрузка 2–6 игроков не подтверждены.
Выпуск остаётся alpha. Рецепты, EMC и внешние моды не менялись.
