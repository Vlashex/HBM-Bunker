# HBM Bunker 0.2.0-alpha.3

Локальный предварительный выпуск от 2026-10-16. Minecraft 1.21.1,
NeoForge 21.1.262, Java 21. Состав прежний: 28 внешних модов, патч HBM Easy
Balance 1.2.0 и собственный Dead Earth; всего 30 JAR.

Добавлен [радиокаталог](../DEAD-EARTH-RADIO.md): три варианта сообщений обнаруженных
станций с ограниченной задержкой, защитой от спама и проверкой целой площадки.
MCP сохраняет семь инструментов; UUID повторяет прежний выбор, конфликтующий
вариант отклоняется. Сырые аргументы проверяются до преобразований SDK.

Импортируй `HBM-Bunker-0.2.0-alpha.3-Prism.zip` в отдельный тестовый профиль.
Gateway из `director/` необязателен; нейросеть не включена. Оператор вручную
размещает станции и включает мост. Погода и разрушительные события ещё не добавлены.

Схема сценариев 1 переносится в 2 с сохранением UUID/сроков и старого сигнала.
Проверены миграция в тестах и отказ от повреждённой очереди без замены данных.
Старые версии собственного мода не читают схему 2: откат делай из резервной копии
всего мира. Пользовательские сохранения не менялись; автоматический перенос
произвольных миров не проверен.

72 JUnit и 18 GameTest прошли; gateway — 12 тестов с настоящим SDK.
На полном сервере и клиенте проверены обнаружение станции, один выбранный сигнал,
повтор, отказ конфликтующего варианта и лимиты; gateway из ZIP также проверен.
После перезапуска сохранены вариант, задержка, квитанции и пауза станции.
См. [результаты проверки](../DEAD-EARTH-RADIO-VERIFICATION.md).
Обычный запуск импортированного Prism ZIP и нагрузка 2–6 игроков не подтверждены.
Релиз остаётся alpha.
