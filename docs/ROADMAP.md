# Следующие этапы

Завершённые срезы отмечены; остальные направления требуют следующих решений и проверок.

## PROJECT DEAD EARTH

Целевой режим: кооператив 2–6 игроков; сервер, клиент и локальный ИИ на одном ПК.
Существующий MVP остаётся основой. Подготовлены архитектура и этапы расширения:

- [Технический roadmap](DEAD-EARTH-ROADMAP.md): мёртвый мир, климат, биосферы,
  WARDEN / OVERSEER / ARBITER, нагрузка, условия приёмки.
- [Сценарии и MCP](DEAD-EARTH-MCP.md): каталог и редактируемые варианты,
  ограниченные полномочия ИИ, исполнение, память и восстановление после сбоев.
- [План первого среза](superpowers/plans/2026-10-16-dead-earth-foundation.md):
  собственный мод, сохраняемые часы и ручной безопасный сценарий.

- [x] Foundation: координатор, часы кампании и безопасный ручной сигнал.
  [Реализация](DEAD-EARTH-FOUNDATION.md) и [проверки](DEAD-EARTH-VERIFICATION.md).
- [x] Expeditions: наблюдения, ручная станция связи и её обнаружение.
- [x] Исправить раннюю инициализацию ProjectE; tooltip smoke в полном dev-клиенте.
- [ ] Подтвердить обычный запуск отдельного профиля PrismLauncher.
- [ ] Пресет мёртвого мира, климат, WARDEN и сценарные адаптеры.
- [x] Первый MCP-мост: семь инструментов, безопасный сигнал, ограниченный transport.
  [Реализация](DEAD-EARTH-MCP-BRIDGE.md) и [проверки](DEAD-EARTH-MCP-VERIFICATION.md).
- [ ] Расширенный каталог, память и локальный OVERSEER.

Климатические моды пока исследованы как кандидаты. Координатор собирается из
`mods/dead-earth/`, gateway — из `director/`; они входят в alpha.2.
Исторический выпуск MVP сохранён.
