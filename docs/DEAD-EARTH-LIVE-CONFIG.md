# Настройки сервера в админке

Рабочая ветка: codex/live-config-admin. Этот срез проходит внутреннюю проверку и затем проверку пользователем в реальной админке. До пользовательской проверки выпуск не упаковывается.

## Форма

Раздел «Настройки сервера» сохраняет оформление существующей панели. «Редактировать» запрашивает актуальную серверную схему, значения и ограничения, открывает поля и сохраняет ранее введённые правки. Данные телеметрии не стирают черновик. Под каждым полем указаны допустимые значения и политика применения.

«Применить» отправляет только горячие изменения; поля из группы «Требуют перезапуска» остаются в черновике. «Применить с перезагрузкой» отправляет весь выбранный набор, сохраняет мир и перезапускает Java внутри того же Minecraft-контейнера. Игроки кратковременно отключаются. Админка показывает сохранение, запуск, подтверждённую готовность или ошибку.

## Контроль

Серверная Java-схема — источник подсказок и политик. Все изменения проходят строгую проверку полного набора; неизвестные поля, неверные типы, NaN/Infinity, выход за границы, устаревшая ревизия/эпоха и попытка горячо изменить структурное поле отклоняются. Сведения о паролях, EULA и произвольных путях в схему не входят.

Применение выполняется в серверном потоке из подготовленных снимков. Незавершённые результаты машин/сит и инвентари не обнуляются. Дальность зрения обновляет существующих загруженных мобов ограниченными порциями; новые мобы используют новую политику. Куски мира принудительно не загружаются.

UUID-квитанция связывает запрос с содержимым; повтор не выполняет действие снова. При неизвестном результате браузер только проверяет квитанцию. Ошибки до отправки позволяют исправить форму и заново открыть редактирование.

Перед заменой файлов сохраняются резервные копии и журнал транзакции. Неполная транзакция восстанавливается до загрузки подсистем. Перезапуск использует фиксированный проверяемый маркер и список разрешённых файлов, не Docker socket. Неудачный запуск допускает одну попытку возврата прежней конфигурации. Неизвестное состояние не отображается как успех.

## Ограничения

Структурные поля и настройки без безопасного живого адаптера требуют перезапуска. Это относится к устройству зон, слотам/ёмкостям, некоторым таймерам, генерации и прогрессии. Перезапуск не переписывает уже созданные чанки и не сбрасывает сохранённую кампанию; настройки таймеров сохраняют существующую семантику расчёта по activeTicks. Следует смотреть подсказку конкретного поля.

Изменения каталога событий через редактор сценариев синхронизируются с редактором конфигов, а текущие операции сохраняют свои графы. Во время ожидающего перезапуска конфликтующие изменения блокируются.

Интерфейс доступен только человеку в локальной админке. Модель и MCP не получают новые команды или доступ к консоли. Проверки Origin/nonce и серверных границ сохраняются.
