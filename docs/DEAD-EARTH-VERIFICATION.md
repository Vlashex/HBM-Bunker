# Проверка Dead Earth Foundation

Дата: **16 октября 2026**. Объект проверки — координатор `0.1.0-dev`,
Minecraft 1.21.1, NeoForge 21.1.262, Java 21.0.3. Это новые проверки;
отчёты исторического MVP не использовались как подтверждение новой логики.

## Автоматические проверки

| Набор | Результат | Что проверяет |
|---|---|---|
| JUnit | 27/27 | Активные часы, схемы, NBT, очереди, дубли, дедлайны, отмена, новая эпоха, прерванное исполнение |
| NeoForge GameTest | 6/6 | Реальные команды/права, запись на диск и загрузка, доставка chat packet, серверный поток, один сигнал, часы при смене времени и без игроков |
| Python сборщик | 7/7 | Существующие проверки исходного репозитория, целостности и документации |

Проверки писались до реализации. Наблюдались ожидаемые отказы отсутствующей логики:
clock/state, ScenarioEngine/ScenarioStore, затем четыре игровых проверки сохранения,
сигнала, команды и интеграции очереди. После реализации они прошли.

GameTest использует отдельный мир в `mods/dead-earth/run-gametest/`.
Подключения embedded-клиентов в нём проверяют настоящие серверные пакеты;
они не считаются испытанием шести обычных игровых клиентов.

## Полная сборка и новый мир

В отдельный стенд `work/foundation-server/` скопированы и проверены по lock-файлу
28 внешних модов. Добавлены существующий балансирующий патч и координатор:
**30 верхнеуровневых JAR**, без исторических тестовых probe-модов.
Создан новый обычный мир `foundation_world`, seed `20261016`.
Сервер слушал только `127.0.0.1:25581`; использовалось 4 ГБ heap.

Подтверждено по результатам исполнения:

- Сервер полностью загрузился; координатор перешёл в `ready`.
- `preview` оставил число сценариев равным нулю.
- Два `submit` одного request UUID вернули один scenario ID и одну ревизию.
- До подключения игрока часы оставались на `0`, включая смену `/time set`.
- Обычный Minecraft dev-клиент с полной сборкой подключился к серверу.
  В его журнале получен один `[DEAD EARTH] Тестовый сигнал` с ID первого сценария.
- Первый сценарий получил `COMPLETED`, revision `2`. Повторная заявка вернула
  ту же завершённую квитанцию и не создала второй сигнал.
- Другой сценарий отменён до исполнения: `CANCELLED`, revision `1`.
- После выхода клиента часы остановились на **2875 активных тиках**.
- Третий сценарий сохранён в `SCHEDULED`; сервер штатно остановлен с кодом `0`.
- После нового запуска того же мира сохранились ID кампании, **2875 тиков**,
  завершённая, отменённая и ожидающая квитанции. Эпоха сервера изменилась.

Прерванный `RUNNING` проверялся через сохранённые тестовые данные и загрузку хранилища.
Настоящее отключение питания и катастрофы HBM не проводились. Этот результат
не является доказательством атомарности произвольного разрушения игрового мира.

## Найденные ограничения

При проверке **полного комплекта в Gradle dev-клиенте** обнаружена ошибка
ProjectE `IEMCProxy`: `No valid ServiceImpl ... found`. Она дала множество ошибок
подсказок JEI, а позднее клиент завершился при показе подсказки в интерфейсе
Outpost Zero. До этого подключение и получение тестового сигнала подтверждены.
Координатор и сервер продолжили работу. Причина отличия dev-запуска от обычного
запуска пока не установлена; ошибка не объявляется исправленной или безусловно
присутствующей в выпускном профиле.

Создан отдельный профиль PrismLauncher `Dead-Earth-Foundation-Test` для проверки
обычного запуска. Запущенный лаунчер пока не распознал его новый instance ID;
чистый обычный клиентский прогон через Prism не подтверждён.

В полной сборке также остаётся известное предупреждение Outpost Zero о
`outpostzero:has_nettle` / `c:plains`. Оно не остановило тестовый сервер.

Не проводились длительная кооперативная сессия 2–6 игроков, измерение p95 MSPT,
проверка всей экономики/GUI ProjectE, новые климатические эффекты и сценарии HBM.
GameTest меняет `dayTime` непосредственно; интерактивное прохождение ночи в кровати
не проводилось. Часы используют отдельный счётчик серверных тиков.

## Состояние поставки

Игровые профили и прежние сохранения пользователя не менялись. Новый мир,
логи, тестовый профиль и зависимости не включены в Git. Выпускной ZIP MVP и
его тег сохраняются; координатор выпускается отдельным артефактом разработки.

Операторские команды, сборка и ограничения описаны в
[руководстве Foundation](DEAD-EARTH-FOUNDATION.md).
