# Клиент DEAD EARTH — без шейдеров

С 5.3.1 MakeUp Ultra Fast, Iris и шейдерные настройки/пресеты удалены.
Клиент Minecraft 1.21.1 / NeoForge 21.1.262 содержит 38 JAR, сервер — 36 JAR.
Координатор 4.2.0 и патч баланса 1.4.0 не менялись.

| Компонент | Версия | Сторона | Назначение |
|---|---|---|---|
| Inventory Sorter |24.0.24|обе|Сортировка средней кнопкой мыши, перенос колёсиком|
| Jade |15.10.6|обе|Информация о блоке под прицелом|
| Block Outline Customizer |1.4.0|клиент|Янтарная рамка блока|
| Sodium |0.6.13|клиент|Отрисовка и обновление чанков|
| FerriteCore |7.0.3|обе|Сокращение расхода памяти|
| ModernFix |5.27.26|обе|Загрузка, память и исправления|

Машинные меню по умолчанию исключены из Inventory Sorter, включая область
инвентаря игрока в открытом меню. Точные проверенные registry ID добавляются
в `convenience.sortingAllowedModMenus` серверного конфига.

## Приоритеты

Глубокая серверная оптимизация выполняется в финальной фазе разработки после
основных механик и баланса. Существующие P01/P02/P03 сохраняются. Регрессии,
ошибки сохранений и обязательные бюджеты исправляются по мере появления.

Переписывание клиентского движка не планируется. Плотные сцены с тяжёлыми
паразитами остаются известным ограничением. Настройки видимости, стоимость
моделей и лимиты сущностей могут менять нагрузку без замены всего движка;
масштабная отдельная работа по клиентской оптимизации сейчас отложена.

Старые замеры с Iris/MakeUp относятся к 5.2.0 и не подтверждают FPS
клиента 5.3.1 без шейдеров. Новые численные обещания производительности не даются.

## Установка и проверка

Сервер 5.3.0 совместим: его моды и игровые данные не менялись. Импортируйте
`HBM-Bunker-5.3.1-Prism.zip` новым профилем, старый сохраните как резервную копию.

Состав закреплён в `metadata/mods.lock.json`; `metadata/shaders.lock.json` —
пустой список. Универсальная поддержка закреплённых шейдеров у сборщика остаётся
для старых выпусков и тестов. Текущая сборка не содержит шейдерных файлов.

```sh
python -m unittest discover -s tests -v
python tools/release.py check
python tools/release.py build
```

Для 5.3.1 проверяются состав, целостность и хеши архива. Повторный настоящий
запуск игры не заявляется. Проверки моделей/мира относятся к 5.3.0.
