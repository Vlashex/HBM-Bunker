# Сайт DEAD EARTH

Адрес: https://vlashex.github.io/HBM-Bunker/ . Сайт находится в том же репозитории, что и сборка. GitHub Pages публикует ветку main, папку /docs. Файл .nojekyll отключает обработку Jekyll.

## Исходники

- docs/index.html — текст, разделы, ссылки, inline SVG-иконки и нативные details FAQ.
- docs/site.css — вся вёрстка, типографика и адаптивность, без JavaScript.
- docs/media/ — шесть WebP-иллюстраций, векторное оформление, шрифты и лицензии.

Иллюстрации — концепт-арт; реальные фотографии и игровые скриншоты не используются по уточнению пользователя. Сайт не подключается к локальной админке, Minecraft, MCP или модели. Он статический и не требует Node, сборщика или сервера приложений. Ссылки на документацию ведут в GitHub; кнопки начала кампании — к установке, не к несуществующему скачиваемому архиву.

После изменения сделайте коммит и push в main: GitHub Pages обновит публикацию автоматически. Версию и доступность архива меняйте согласованно с release.json и действительными GitHub Releases. Игровой релиз из-за одной правки сайта не нужен.

Для локальной проверки можно открыть docs/index.html или запустить python -m http.server 8080 --directory docs. На этом срезе Computer Use остаётся остановленным; браузерная проверка интерфейса не заявляется. Проверяются разметка, ссылки/якоря, наличие ресурсов, отсутствие скриптов и HTTP-ответы опубликованной страницы.
