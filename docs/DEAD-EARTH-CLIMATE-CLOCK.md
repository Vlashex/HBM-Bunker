# DEAD EARTH — климатические часы и прогноз

Первый климатический срез хранит расписание и выдаёт прогноз. В этой версии нет
урона от температуры, изменения погоды, снега/льда или управления биосферами.
В MCP-снимке это обозначено `climateEffectsEnabled: false`.

## Расписание

| Шаг | phase | trend | Длительность по умолчанию |
|---|---|---|---|
| Подготовка / потепление | CALM | WARMING | 48000 активных тиков, 2 игровых дня |
| Жара | HEAT | NONE | 2 дня |
| Охлаждение | CALM | COOLING | 2 дня |
| Пепельная зима | ASH_WINTER | NONE | 2 дня |

Далее цикл повторяется. При 20 TPS полный круг — 8 игровых дней / 160 минут.
CALM — одна фаза с направлением перехода. Новая установка начинает подготовку
от текущих часов кампании: старый мир не объявляется уже пережившим зиму.

Единственный источник времени — activeTicks кампании. Когда нет игроков,
часы стоят. Сон и команды смены времени суток не сокращают расписание.
Отдельных часов реального времени или зависимости от ИИ нет.

## Статус и уведомления

Операторские команды с правом 2:

```text
/deadearth climate status
/deadearth climate forecast
```

Status возвращает режим forecast_only, текущую фазу, направление, номер цикла,
originTick, enteredTick, nextTransitionTick и ticksRemaining. Forecast показывает
четыре следующих ограниченных окна. Команды только читают состояние.
Те же текущие сведения доступны через get_snapshot в существующем MCP, без
добавления инструмента переключения фаз. Возраст кеша по-прежнему возвращается.

При наличии игроков сервер один раз объявляет текущий шаг и один раз предупреждает
о следующем за 6000 активных тиков (5 минут) до перехода. После загрузки повтор
уже записанного уведомления не отправляется. При пропуске нескольких шагов
сообщается текущее состояние, историческая очередь сообщений не воспроизводится.

## Сохранения и границы

`dead_earth_climate.dat`, схема 1, привязан к кампании. Хранятся начало цикла,
длительность и маркеры уведомлений. Маркеры сохраняются до сообщения: редкий сбой
между записью и доставкой может потерять уведомление, автоматического повтора нет.
Это не атомарная транзакция всех файлов мира.

Длительность закреплена в сохранении. Runtime создаёт профиль 48000; короткий
профиль используется в тестах, переключателя для игроков/MCP нет. Проверяется
диапазон 200..1920000 с шагом 20. Повреждённая, чужая, будущая схема или маркер
из будущего сохраняются без замены и отключают координатор. Переполнение времени
не переводит цикл в прошлое.

Полный круг проверяется детерминированными тестами. Короткий клиентский прогон
проверяет только начальную фазу, снимок, остановку времени и восстановление;
он не является 160-минутной симуляцией погоды. Физические эффекты, укрытия,
адаптеры леса/паразитов и температурная интеграция — следующие срезы.
