# Проверка MCP-моста — 2026-10-16

Проверялся отдельный мир `mcp_world`, seed 2026101603, localhost:25583,
Minecraft 1.21.1 / NeoForge 21.1.262 / Java 21, полные 30 JAR. Пользовательские
профили и сохранения не использовались. Условия: creative, peaceful, один dev-клиент.

## Автоматические проверки

- 64 JUnit: протокол, очередь, кеш и предыдущая логика кампании.
- 16 GameTest в новой папке: прежние 13 и три проверки моста.
- 9 Python: проверка дескриптора/протокола и настоящий SDK stdio round-trip.
- 13 Python упаковки: исходники gateway включаются разрешённым списком,
  виртуальная среда, тесты, кеши и runtime-дескриптор исключены.

GameTest выполнены на накопленный срез; позднее исправление отправки ответа
проверено всем набором 64 JUnit. Отдельный RED-тест воспроизвёл блокировку первым
нечитающим клиентом; GREEN подтвердил обслуживание второго после дедлайна.
Аналогично воспроизведены и исправлены медленные фрагменты ввода и маскировка
ожидаемой ошибки официальным SDK. Свежий финальный review выявил один P2
по отправке ответа; он исправлен, других actionable замечаний не найдено.

## Реальная полная сборка и SDK

Через официальный MCP Client проверены ровно семь инструментов и один шаблон
warning_beacon_v1. Сигнал поставлен, повтор request_id вернул тот же scenarioId.
Другой сигнал отменён. Подключённый dev-клиент получил одну строку DEAD EARTH;
отменённый сигнал не появился. Клиент завершился без ошибки, ProjectE tooltip
smoke также прошёл.

При отключении игроков кеш обновился, часы остановились. Неизвестный инструмент
execute_command отклонён. Остановка моста не остановила кампанию; gateway со старым
дескриптором перестал работать после смены токена, свежий процесс подключился.

Первые два полных запуска сервера завершились exit 0. На втором запуске:
идентификатор кампании сохранён, эпоха изменена, 602 активных тика и состояния
COMPLETED/CANCELLED восстановлены. Свежий токен со старой эпохой дал stale_context;
повтор исходного request_id сохранил завершённую квитанцию.

Окончательный JAR проверен повторным SDK-прогоном на третьем запуске сервера;
все три сервера завершились exit 0.
Из кандидата ZIP извлечены восемь файлов director; setup.ps1 создал свежую среду
и установил 29 дистрибутивов с проверкой хешей. Gateway из этой среды сообщил
семь инструментов и получил реальный снимок и каталог с сервера.

## Границы вывода

Не проверены шесть игроков, производительность большой карты и обычный запуск
импортированного Prism-профиля. Проверка dev-клиента этого не заменяет.
Шаблон не ломает блоки и не спавнит существ; это проверка транспорта и полномочий,
а не подтверждение боевых событий или нейросетевого режиссёра.
Полные журналы, сокетные дескрипторы и миры остаются локально вне Git и ZIP.
