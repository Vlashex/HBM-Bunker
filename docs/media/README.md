# Визуальные материалы сайта

hero.webp, forest.webp, parasites.webp, heat.webp, winter.webp и bunker.webp — сгенерированный для проекта концепт-арт, не игровые скриншоты и не реальные фотографии. Каждая сцена создана отдельно, в едином художественном направлении. WebP — перекодирование исходных PNG без кадрирования и изменения содержания,1536×1024. На сайте галерея явно помечена как концепция.

cover.svg и mark.svg — исходные векторные элементы оформления проекта. Чужие логотипы не копировались.

Шрифты Oswald и Golos Text загружены из официального Google Fonts и размещены локально (латиница и кириллица). Лицензии: oswald-OFL.txt и golostext-OFL.txt. Исходники: https://github.com/google/fonts/tree/main/ofl/oswald и https://github.com/google/fonts/tree/main/ofl/golostext .
