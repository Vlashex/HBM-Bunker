# Оптимизации после v5: анализ, проверки и откат

База — `v5.0.0` (`d20e245`), отдельная ветка — `perf/dead-earth-post-v5`.
Здесь зафиксирован проверенный срез исходников. Работающий сервер, профиль Prism,
готовые архивы v5 и пины релиза не обновлялись. Новый бинарный релиз не собран.

Это статус исходного среза оптимизаций. Следующий локальный выпуск
[5.1.0](../releases/5.1.0.md) включает эти три коммита и постановку событий;
их самостоятельные границы и команды отката сохранены.

| ID | Самостоятельный коммит | Изменение |
|---|---|---|
| P01 | `1dfadc7` | Неизменяемая геометрия наледи кешируется для радиусов 0…10. При стандартном радиусе устранены 24 отдельных массива на попытку колонки; порядок опор и направление покрытия сохранены. |
| P02 | `b8b25fc` | Отчёт зоны и копия списка турелей создаются один раз на затронутое задание за тик, вместо каждого шага/слота. Частичные результаты и ошибки сохраняются. |
| P03 | `22be566` | Периодические Gson-кодирование и подготовка JSON-проекции выполняются одним daemon-потоком. Не более одного выполняемого и одного последнего ожидающего снимка. |

Каждый коммит содержит собственный код, проверки и заметку P01/P02/P03 в этой
папке. Их наборы файлов не пересекаются. Для каждого независимо выполнена
`git apply --reverse --check` относительно общего результата: все три проверки
успешны. Форматы SavedData, конфиги, seed, коэффициенты и рецепты не изменены.

## Как откатить

В чистой рабочей копии выберите нужный коммит:

```sh
git revert 1dfadc7   # только кеш геометрии наледи
git revert b8b25fc   # только пакетная публикация отчётов зон
git revert 22be566   # только фоновая сериализация моста
```

Команды независимы; не обязательно выполнять все три. Для возврата всех
оптимизаций можно откатить их от нового к старому. После отката пересоберите
мод и проверьте соответствующие тесты. Установленный JAR от Git-команды сам
не изменится. Миграция/откат мира не требуются.

## Граница многопоточности

Факты собираются на серверном потоке в неизменяемые DTO. Worker не получает
Level, Chunk, Entity, ItemStack, NBT, конфиг или доступ к инвентарям. Первый кеш
при запуске моста готовится синхронно; периодические обновления появляются после
окончания кодирования, пока читатели используют предыдущий кеш. Возраст данных
считается от capture и включает ожидание/кодирование. Ошибка сохраняет прежний
кеш; закрытие не ждёт encoder и запрещает позднюю публикацию.

Чтение мира, расчёт физических запасов, эффекты и барьер сохранения перед
APPLYING продолжают выполняться на владельце сервера. Мост выключен по умолчанию;
при выключенном мосте его worker не создаётся. Дополнительных модов нет.

## Подтверждённые проверки

173 Java unit-теста, 87 GameTest с полным серверным составом в новом мире,
16 тестов упаковщика и source check прошли. Сами игровые тесты заняли 34.48 с,
весь Gradle-прогон — 2 мин 26 с с загрузкой модов. Проверены геометрия/бюджеты
наледи, настоящее чтение сундука, число публикаций, частичный прогресс и ошибка
сканирования, coalescing, сбой/закрытие/перезапуск worker и возраст кеша.
Предварительные RED-прогоны подтвердили исходные повторные выделения и публикации.

[Машинное свидетельство](../../verification/performance/post-v5.json) относится
к указанным трём коммитам. После последующих изменений или откатов результаты
могут отличаться. Сравнение MSPT/FPS обычного игрового мира не проводилось;
подсчёт устранённых операций не является обещанием определённого прироста TPS.

## Следующие кандидаты после измерений

- `WastelandField.displacement`: раннее отсечение далёких кратеров до atan2/sin/hypot,
  с проверкой точного совпадения прежнего поля высот.
- `CinematicEngine.options`: вычисление лотерейного ключа один раз на кандидата
  вместо повторного MD5/log в comparator, с сохранением порядка и tie-breaks.
- Защита бункера: грубое пространственное отсечение перед обходом отдельных
  комнат, сохраняя проверку полного swept AABB для быстрых перемещений.

Дополнительный executor для каждой колонки наледи или каждого моба пока не
оправдан: основная работа обращается к текущему миру, а чистые вычисления малы.
Генерация мира уже работает через нативные worldgen workers.
