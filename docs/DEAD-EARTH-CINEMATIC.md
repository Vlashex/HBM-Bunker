## Изменение без пересборки

Файл сервера: `config/dead-earth/director/catalog.json`. В сборке канонический источник — `pack/config/dead-earth/director/catalog.json`. В JAR вложен резервный каталог. После правки оператор выполняет `/deadearth director reload`. Некорректный файл отклоняется целиком; текущий каталог остаётся действующим. Уже принятые операции продолжают сохранённый граф.

В `rules` задаются частота решений, срок выбора, квоты очереди, передышки, ограничения волн, коэффициенты score и радиусы. В `rules.coefficients` также вынесены веса уровня/брони игроков, памяти смертей, защиты, нормализации, радиусы реакции, квоты следов/вариантов и краткий повтор сканирования после старта. В `sounds` — зарегистрированный звук, громкость и высота тона. В `traces` — цвет и прямоугольная маска 4–16 строк/столбцов (`.` — пустота, `1/2/3` — плотность). В `waves` — список зарегистрированных типов мобов.

Событие содержит уникальный `id`, название, тактику, сторону, вес, минимальный score/число игроков, сезоны, сроки, флаг тяжёлой связки, коэффициенты `affinity`, стартовый узел и список узлов. `affinity` использует value, defense, empty_defense, pressure, players, losses.

Каждый узел выполняет `actions`, затем ждёт `waitTicks`. В `branches` перечислены условия и следующие узлы по приоритету; `timeout` задаёт выход по сроку. Все пути конечны, циклы и недостижимые узлы отклоняются. Условия: near, far, inspect, break, burn, water, mine, repair, clear. При необходимости указывается роль: `near:rear`, `inspect:flank`. Роли: approach/flank/rear/distraction.

Действия: sound, trace, particles, wave, move, finish. Для sound/trace/wave `key` ссылается на соответствующую библиотеку; particles: spores/ash/frost/dust; move: роль подхода; finish: repelled/contained/avoided/engaged/inconclusive. Все действия имеют поля type/key/role/portion; portion у волны — доля конечного бюджета операции. Новая композиция этих действий не требует Java; новая физическая механика требует нового адаптера.

Модель получает компактный список вариантов, сезон, давление и последние исходы. Ответ — только `{"option": индекс}`. Python переводит индекс в разрешённую пару event_id/zone_id, сервер повторно проверяет допуск. Произвольных координат, численности и консольных команд в контракте нет.

## Запуск и наблюдение

Режиссёр включается через `director.enabled=true` в серверном конфиге собственного мода; по умолчанию выключен. Мост включается оператором. Host запускается с `--mode live`; прежний режим `--mode preview` остаётся доступным. Модель работает только на CPU. Если она недоступна, используется серверный список; на стороне сервера также есть конечный таймаут ожидания выбора.

`/deadearth director` показывает состояние, `/deadearth director queue` — очередь, `/deadearth director cancel <UUID>` отменяет будущие шаги. Отмена не удаляет автоматически уже созданных мобов; у них собственный конечный срок жизни. MCP: get_cinematic_brief, choose_cinematic, get_cinematic_queue. Единый BAT остаётся следующим обязательным срезом.

Неполные, старые и переполненные сканы не выбираются для атаки. Сценарии не загружают чанки и не заменяют убитых на подходе врагов. Успешная оборона даёт передышку. Сохранения неизвестной схемы сохраняются, незавершённый APPLYING получает исход uncertain.
