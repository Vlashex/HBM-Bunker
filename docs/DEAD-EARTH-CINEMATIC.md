# Интерактивный режиссёр DEAD EARTH — рабочая ветка

Это описание разрабатываемого расширения v3. Выпущенная 3.1.0 содержит только D1 preview. Сквозная проверка CPU-модели и клиента прошла; новый релиз ещё готовится. Доказательства и ограничения — в `verification/director-cinematic/`.

## Изменение без пересборки

Файл сервера: `config/dead-earth/director/catalog.json`. В сборке канонический источник — `pack/config/dead-earth/director/catalog.json`. В JAR вложен резервный каталог. После правки оператор выполняет `/deadearth director reload`. Некорректный файл отклоняется целиком; текущий каталог остаётся действующим. Уже принятые операции продолжают сохранённый граф.

В `rules` задаются частота решений, срок выбора, квоты очереди, передышки, ограничения волн, коэффициенты score и радиусы. В `rules.coefficients` также вынесены веса уровня/брони игроков, памяти смертей, защиты, нормализации, радиусы реакции, квоты следов/вариантов, допустимый перепад высоты подхода (`maximumApproachHeightDifference`, по умолчанию 12 блоков) и краткий повтор сканирования после старта. В `sounds` — зарегистрированный звук, громкость и высота тона. В `traces` — цвет и прямоугольная маска 4–16 строк/столбцов (`.` — пустота, `1/2/3` — плотность). В `waves` — список зарегистрированных типов мобов.

Событие содержит уникальный `id`, название, тактику, сторону, вес, минимальный score/число игроков, сезоны, сроки, флаг тяжёлой связки, коэффициенты `affinity`, стартовый узел и список узлов. `affinity` использует value, defense, empty_defense, pressure, players, losses.

Каждый узел выполняет `actions`, затем ждёт `waitTicks`. В `branches` перечислены условия и следующие узлы по приоритету; `timeout` задаёт выход по сроку. Все пути конечны, циклы и недостижимые узлы отклоняются. Условия: near, far, inspect, break, burn, water, mine, repair, clear. При необходимости указывается роль: `near:rear`, `inspect:flank`. Роли: approach/flank/rear/distraction.

Действия: sound, trace, particles, wave, move, finish. Для sound/trace/wave `key` ссылается на соответствующую библиотеку; particles: spores/ash/frost/dust; move: роль подхода; finish: repelled/contained/avoided/engaged/inconclusive. Все действия имеют поля type/key/role/portion; portion у волны — доля конечного бюджета операции. Новая композиция этих действий не требует Java; новая физическая механика требует нового адаптера.

Модель получает компактный список вариантов, сезон, давление и последние исходы. Ответ — только `{"option": индекс}`. Python переводит индекс в разрешённую пару event_id/zone_id, сервер повторно проверяет допуск. Произвольных координат, численности и консольных команд в контракте нет.

## Запуск и наблюдение

Режиссёр включается через `director.enabled=true` в серверном конфиге собственного мода; по умолчанию выключен. Мост включается оператором. Host запускается с `--mode live`; прежний режим `--mode preview` остаётся доступным. Модель работает только на CPU. Если она недоступна, используется серверный список; на стороне сервера также есть конечный таймаут ожидания выбора.

`/deadearth director` показывает состояние, `/deadearth director queue` — очередь, `/deadearth director cancel <UUID>` отменяет будущие шаги. Отмена не удаляет автоматически уже созданных мобов; у них собственный конечный срок жизни. MCP: get_cinematic_brief, choose_cinematic, get_cinematic_queue. Единый BAT остаётся следующим обязательным срезом.

Неоткрытые контейнеры со случайным лутом пропускаются до открытия и отражаются в `ignoredLootContainers`; сами по себе они не блокируют выбор события. Остальные неполные, старые и переполненные сканы не выбираются для атаки. Сценарии не загружают чанки и не заменяют убитых на подходе врагов. Успешная оборона даёт передышку. Сохранения неизвестной схемы и нечитаемый файл сохраняются; отключается только режиссёр. Незавершённый APPLYING получает исход uncertain. UUID живой волны остаются в сохранённом учёте после выгрузки чанка: отсутствие загруженного моба не означает победу и не освобождает лимит. Смерть или конечный срок освобождают учёт. Отменённая добыча не запускает засаду; подтверждение не загружает старый чанк.

## Постановка и реакции

| Событие | Предвестник | Действие игрока → ответ мира |
|---|---|---|
| Шорохи на фланге | Шорох паука, когти на земле | Осмотреть/подойти → разведчики с тыла; игнорировать → слабая фронтальная проба; уйти → отступление |
| Споровая приманка | Лесной звук, зелёная пыль | Вода → источник подавлен; огонь → пепел и отступление; приблизиться → споры и лесные разведчики |
| Тишина перед выводком | Дыхание, волочащийся след | Разрушить/сжечь → ранняя малая волна; ждать → более крупная волна из того же конечного бюджета |
| Ложная осада | Шум впереди, когти | Пойти на звук → проба с тыла; усилить оборону/выждать → слабая фронтальная проба |
| Два следа | Лапы на фланге, корни с тыла | Исследовать один путь → соответствующая сторона отвечает; при одновременных действиях порядок ветвей задаёт приоритет |
| Подземный ритм | Глухой стук, трещины | Копать у следа → засада с открытого фланга; залить/уйти → затихание; выждать → поверхностная проба |
| Проверка обороны | Звон металла, след кабеля | Реально увеличить ранг заряженной защиты → враг медлит/отходит; оставить уязвимость → разведывательная атака |
| Ночная миграция | Цепочка следов и шаги | Перехватить → группа вступает в контакт; выждать → группе передаётся команда перехода к другому краю; путь остаётся задачей нативной навигации |
| Заражающий туман | Споры и зелёные следы | Вода → подавление; огонь → дым; подойти к источнику → лесные разведчики; уничтожить источник → прекращение локального давления |
| Холодный очаг | Звон льда, морозная пыль | Согреть огнём → интерес паразитов с тыла; осмотреть → слабая лесная проба; вода → локальное затихание. Только зимой |
| Сухая гроза | Потрескивание, пепельное кольцо | Вода → затихание; огонь → разведчики с тыла; исследование/ожидание → лесная проба. Только летом |
| Эхо из периметра | Ритм помех, след кабеля | Изучить → появляется второй след с тыла; идти сразу на сигнал → фланговая засада; прочитать второй след → меньшая встречная проба |
| Сорванный сбор | Корни и треск почвы | Добыча/разрушение у следа → защитники леса; вода → подавление источника; огонь/уход → отступление |
| Ложный выдох | Малая проба, затем удаляющийся звук | Преследовать тыловой след → вторая часть исходного бюджета; заняться обороной/выждать → противник отходит |
| Перекрёстный фронт | Разные следы на двух направлениях | Подавить лес → остаются паразиты; уйти к паразитам → отвечает лес; усилить защиту → оба направления затихают; ждать → две ограниченные группы |

Фактическое число противников рассчитывается отдельно и может оказаться меньше из-за защиты, потерь игроков или отсутствия допустимых точек. «Источники» здесь — наши следы и локальные эффекты; сценарий не выдаёт их за изменение глобальной нативной стадии леса. Враг не повреждает исправные двери или турели ради постановки. Крупная связка имеет отдельный cooldown.
