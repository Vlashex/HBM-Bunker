# DEAD EARTH — локальный MCP-мост

Продолжение [MCP-контракта](../../DEAD-EARTH-MCP.md) после Expeditions.
Пользователь разрешил автономную разработку, пакетные игровые проверки и локальные выпуски.

## Первый результат

Отдельный MCP-процесс читает факты кампании и предлагает только уже реализованный
безопасный сигнал. Нейросети, спавнов, консоли, файловых инструментов и произвольных
команд нет. Этот срез проверяет связь и полномочия перед игровым каталогом и OVERSEER.

## Контракт

- Java-мост выключен по умолчанию. Оператор запускает и останавливает его командами
  `deadearth bridge start`, `status`, `stop` с правом 2.
- TCP только `127.0.0.1`, случайный свободный порт, 256-битный токен на запуск.
  JSON-дескриптор в корне сохранения содержит адрес, токен, UUID кампании и эпохи.
  Токен никогда не печатается и не включается в Git/релиз.
- Одно JSON-сообщение на соединение, UTF-8 с LF, максимум 8192 входных байта,
  глубина 16, ответ до 262144 байт, ограниченные ожидания и один I/O-поток.
- Запрос содержит protocol=1, token, campaign_id, world_epoch, operation, arguments.
  Неизвестные операции/поля отклоняются. Старая эпоха не принимается.
- Кеш снимка обновляется на главном потоке каждые 200 серверных тиков, в том числе
  без игроков. В ответе возраст кеша; максимум 64 игрока, 128 последних известных
  регионов, 100 событий истории и 64 известных объекта, с количеством пропущенных.
- Чтение кеша не обращается к миру из I/O-потока. Изменяющие запросы помещаются
  в очередь максимум 32, обрабатываются по два за тик с проверкой живого runtime.
  Не начатые просроченные запросы не исполняются; уже принятый сценарий имеет свой ID.
- Инструменты: get_snapshot, get_history(limit 1..100), list_catalog,
  preview_scenario(request_id), propose_scenario(request_id),
  get_scenario_status(scenario_id), cancel_scenario(scenario_id, revision).
  Единственный catalogId — warning_beacon_v1; границы Foundation сохраняются.
- Повтор propose с тем же UUID возвращает прежний сценарий. Внешняя отмена RPC
  не откатывает уже принятое событие. Сервер продолжает работу без MCP-процесса.
- MCP stdio использует официальный Python SDK, закреплённый mcp 2.3.0
  ([PyPI](https://pypi.org/project/mcp/2.3.0/)); отдельная локальная venv, без изменения
  Python пользователя. Transitive lock с хешами для текущей Windows/Python 3.12.
- Python клиент принимает только loopback-дескриптор и проверяет кампанию/эпоху ответа;
  не позволяет заменить endpoint внешним адресом. stdout содержит только MCP.

## Проверка

Узкие тесты: токен, эпоха, размеры, вложенность, неизвестные поля, очереди/таймаут,
остановка, неизменяемость кеша, отсутствие произвольных инструментов.
После накопления среза: весь Java/Python набор, GameTest, MCP initialization/tools
реальным SDK, полный сервер в отдельном мире, дубли сигнала, отключение MCP,
перезапуск/старая эпоха. Клиент повторять при изменении затрагиваемого поведения,
а не после каждого коммита. Один заключительный read-only review и локальный alpha.
