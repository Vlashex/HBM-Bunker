# DEAD EARTH SRP full fork design

Approved continuation: user requests complete 1.12.2 fork, including wasteland, thick winter, defense V1/V2/V3 and all remaining mechanics/mods. Client/server/real AI verification ONLY after implementation. Existing modern installation/worlds untouched; work exclusively C:/projects/DEAD-EARTH-SRP, branch fork/srp-1.12.2. Base a216136.

## Content parity
Original SRP+Epic Siege replace Mutationcraft/Improved Mobs/OV; forest removed by request. SecurityCraft removed; defense and automation depend on HBM. Native legacy AE2, Mystical Agriculture, ProjectE, RFTools, sieves, inventory sorting, HUD and performance mods use pinned official builds. Unavailable modern mods get lightweight equivalents or focused additions to coordinator: compact crop trays, area mining tools/charger if needed, shelter generator and defense. Keep all requested gameplay loops: cheap shared chest search before ME, simple/ME autocrafting, sieves+resource plants, energy exchange limited to raw resources, HBM metallurgy, high enchantment books, food/water, area mining3/5/7 and silk/Fortune processing. No Tinkers or shaders. Dependencies only where required. Each modern mod gets an explicit mapping with reason.

## Worldgen
Overworld remains native terrain/ores/biomes, with an inert stone/ash/rubble surface, dead trunks, dirty colored water, many small/rare large craters. No ambient added radiation or radioactive palette. Keep all HBM structures; suppress vanilla surface villages/temples/mansions/tree/grass generation only, keep underground/underwater/other dimensions. Never rewrite existing player chunks. Deterministic absolute-coordinate crater field; writes only current chunk and capped budget. Preserve HBM architecture and container footprints; avoid hanging pillars from mossy/other natural blocks.

## Seasons
Active campaign clock remains authority. Winter coats tops AND sides with several blocks of own reversible ice/snow, with smooth noise and rare peaks seeded per winter. Gradual bounded updates/section budget; loaded chunks only, catchup queued on load, no forced terrain loading. Thaw removes only own coating, never player blocks/native ice. Machinery/containers/protected doors remain operable. Summer heat/fire/exposure and winter cold effects, client visible seasonal weather/fog/particles; all coefficients and budgets in server config. SRP winter1.8/summer0.5 preserved.

## Defense and shelter
Own wall/door/hatch tiers V1=1000,V2=2000,V3=8000 HP. HBM progression, original bunker-like steel visuals with darker upper tiers. Reusable HBM tool for V1 inventory crafting; V1 consumed in V2/V3. V3 resists SRP conversion/griefing bypass; no special nuclear immunity. Track actual hostile block attempts via narrow guards, apply finite damage/cooldown, persist sparse damage; player mining allowed with drops. Own modest shared starter shelter, grace first3 active hours,6 zone relays/dirt/saplings delivered once per world.

## Integration interfaces
Each subsystem owns its package/assets and registers Forge event listener once via static install(Path config). Root owns DeadEarthLegacy/LegacyRuntime/core transformer/Reflect/settings/build tools and final integration. Subsystems may reference public LegacyRuntime server/settings/campaign/world/worldDirectory and onOwnerThread(). Worldgen: dev.deadearth.legacy.worldgen.LegacyWasteland.install(Path), registerBlocks(Object), registerItems(Object), registerModels(). Climate: dev.deadearth.legacy.climate.LegacyClimate same install/register methods, tick(LegacyRuntime), close(). Defense: dev.deadearth.legacy.defense.LegacyDefense same install/register methods, allowChange(Object world,Object pos,Object proposedState):boolean, isDefense(Object block):boolean. Registration invoked in root existing Forge registry/model events. No edits to shared entrypoints by subsystem workers. New subsystem configuration lives in config/dead-earth/{worldgen,climate,defense}.json. World access exclusively owner server thread; client event logic checks logical side and never invokes server runtime.
