# DEAD EARTH Expeditions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Наблюдение за командой, первая станция связи и воспроизводимая поставка.
**Architecture:** Java хранит факты и объекты рядом с Foundation; операторские
команды используют главный поток; внешние моды не получают новые полномочия.
**Tech Stack:** Java 21 / NeoForge 21.1.262 / Gradle / Python 3.11+.
**Spec:** [Expeditions](../specs/2026-10-16-expeditions-design.md).

## Global Constraints

Пользователь разрешил автономное выполнение и локальные релизы. Игровые проверки
проводить после связного набора изменений, не после каждого коммита. Не менять
пользовательские миры, версии внешних модов, HBM-рецепты или remote.

## Review Focus

1. Инициализация ProjectE в фоновом потоке; отсутствие мода не мешает запуску.
2. Смешение миров или ошибочные схемы не заменяют существующие данные.
3. Отрицательные координаты регионов и ограниченный объём наблюдений.
4. Размещение не перезаписывает блоки и не загружает удалённые чанки.
5. Сбой размещения не допускает автоматического повторного разрушения/постройки.

### Task 1: Диагностика ProjectE и узкая совместимость
- [ ] Подтвердить вызов ServiceLoader и первый поток по JAR/журналу.

- [ ] Зафиксировать проверенную границу и коммит; реальный клиент отложить до конца среза.

### Task 2: Ограниченные наблюдения

`ObservationLogTest.java`, `ObservationStoreTest.java`.
**Interfaces:** `sample(UUID player, String dimension, int x, int z, float health, long tick)`,
`death(...)`, immutable `snapshot()`; store binds campaign UUID.
- [ ] RED: повторный регион, отрицательные координаты, лимиты, история и неизвестная схема.
- [ ] Реализовать журнал, NBT, периодическое наблюдение, смерти и команды.
- [ ] Проверить затронутые unit-тесты; коммит.

### Task 3: Станция связи и обнаружение

- [ ] Проверить затронутые unit-тесты; коммит.
