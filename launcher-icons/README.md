# DEAD EARTH server shortcut icons

Generated with the built-in image_gen tool on 2026-10-18 for the Windows server
shortcuts. Original PNGs are retained. ICO files encode the same artwork at
16, 24, 32, 48, 64, 128 and 256 pixels, preserving transparency.

Run `powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/install-server-shortcuts.ps1`
from the repository to create the two desktop shortcuts. The start shortcut
targets start-dead-earth.bat; the stop shortcut targets stop-dead-earth.bat,
which requests the existing supervisor's normal save/shutdown path.
